# 実装計画: スタート横並び整列・内外進路取り＆スペース探索追い抜き物理・馬番修正・JRA中継風HUD刷新

## 概要
ユーザーからの要望および添付画像（JRA公式競馬中継画面）に基づき、以下の4つの主要機能を実装・刷新します：

1. **スタート時の横並び整列（内側1番〜外側順番並び）**
2. **馬番の異常値（25番等）の根本防止（最大18頭枠・完全整合ガード）**
3. **内側重視の走行＆開いているスペースを探して追い抜く動的進路選択物理シミュレーション**
4. **スクリーンショットに準拠したJRAテレビ中継風リアルタイムHUD（隊列レーダー・コースマップ・時速/勾配・上位馬テロップ）の刷新**

---

## ユーザー確認事項・設計方針

> [!IMPORTANT]
> - **スタート整列**: スタートライン（`dist = 0`）において、馬番1番が最内ラチ沿い、2番, 3番...と外側に向かってゲート順に完全に横並びで配置されます。
> - **走行ラインと追い抜き**: 基本は全頭内ラチ沿い（最短コース）を目指しますが、前走馬との前後間隔が詰まった（前壁）場合、内側スペースがあれば内へ、塞がっていれば外側へスムーズに進路変更して交わします。馬の幅は約2.0m（馬体幅+安全マージン）とし、前後の隙間を正確に判定します。
> - **JRA中継風HUD**: 添付スクリーンショットに基づき、画面下部に「リアルタイム隊列インジケーター（JRA枠色丸ゼッケンが内外×前後のリアルな位置で動くグラフィック）」、「コースマップ＆時速(km/h)・勾配(%)」、「上位馬情報＆レース名・競馬場名」を忠実に再現・配置します。

## 詳細設計

### 1. スタート横並び ＆ 動的進路変更・追い抜きシミュレーション (`src/race/engine.py`)
- コース幅を $W = 20.0\,\text{m}$、最内ラチ沿いを $0.6\,\text{m}$ とする。
- **スタート初期値 ($t=0$)**:
  - 各馬の走破距離: $dist = 0.0\,\text{m}$（横一線）
  - 各馬の横位置: $lateral = 0.6 + (gate\_num - 1) \times \frac{W - 2.0}{\text{total\_starters} - 1}$
    （1番が最内、番号順に外側へ整然と並ぶ）
- **0.1秒ごとの更新ステップ**:
  - 各馬の目標横位置 `target_lateral` を設定：
    - 基本は最内ラチ沿い ($0.6 \sim 1.5\,\text{m}$) を目指して内へ切れ込む。
  - **前方ブロッキング（前壁）判定**:
    - 自馬の前方 $0 < \Delta dist < 3.0\,\text{m}$（約1.2馬身）かつ横差 $|\Delta lateral| < 1.6\,\text{m}$ に他馬が存在する場合、「前壁」と判定。
  - **スペース探索（進路変更）**:
    - 内側スペース（$lateral - 1.8\,\text{m}$）がラチ以上かつ他馬がいない場合 $\to$ **内側を突く**
    - 内側が塞がっている場合 $\to$ **外側へ持ち出す**（$lateral + 1.8\,\text{m}$）
  - スムーズなレーン移動速度（最大 $1.2\,\text{m/s}$）で現在の `lateral` を `target_lateral` に滑らかに追従。
  - 最終直線（残り300m）では外に持ち出した馬が豪快に差し切る展開を再現。

### 2. 馬番（gate_number）の異常値防止
- `gate_number` は必ず $1 \le gate\_number \le \text{total\_starters} \le 18$ を保証。
- `number = min(18, max(1, int(gate_number)))` による徹底的なガード。

### 3. JRA中継風HUDの刷新 (`src/gui/widgets/track_canvas.py`)
添付画像のUI要素を画面下部に美しく集約：
1. **画面中央下：リアルタイム隊列インジケーター (Live Running Order / Radar)**:
   - レース中の各馬の位置（横軸＝先頭からの前後差、縦軸＝最内〜大外の横位置）に、JRA公式枠色丸ゼッケン（①〜⑱）をリアルタイムにアニメーション描画。
   - 残りハロン棒ライン（例: `1800m`、`1600m` 等）の縦線。
2. **画面左下：競馬場コースマップ＆テレメトリー**:
   - 競馬場の立体レイアウト図、`TURF / DIRT 距離m`
   - 勾配インジケーター（`◿ 2%` / `flat`）
   - 先頭馬のリアルタイム計測時速（`◷ 58.2 km/h`）
3. **画面右下：上位馬LIVEテロップ**:
   - トップ3の枠番・馬番バッジ・馬名
   - JRA公式風ロゴ ＆ レース名 ＆ 競馬場名

## 検証手順

1. **スタート整列＆追い抜きシミュレーションの検証**:
   - スタートフレーム（$t=0$）で全馬の $dist=0$ かつ横位置が1番から順に綺麗に内から外へ並んでいることを自動テストで検証。
   - レース道中で前壁発生時に外または内へ進路変更し、馬同士の重なりが自然に回避されていることを確認。
   - 最大馬番が18以内であり、25番などの異常値が一切出現しないことを検証。
2. **描画＆HUDレイアウトの確認**:
   - 画面下部の隊列インジケーター、コースマップ、時速・勾配表示、上位馬テロップが添付画像通りにレンダリングされることをオフスクリーンテストで検証。
3. **既存テストスイートの全件合格**:
   - `python3 -m unittest discover -s tests` の全件パスを確認。
