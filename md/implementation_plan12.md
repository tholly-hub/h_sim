# 2Dレースシーン・ブラッシュアップ及びコース・馬番仕様改善計画

ユーザー様からいただいた以下のご要望に基づき、2Dレース画面の高品質化とシミュレーションの整合性向上を実施します。

1. **当面は2D表示を基本とし、徹底的にブラッシュアップを図る**
2. **ゴールすると馬番がすべて1番になる問題の根本修復**
3. **コース幅を広げ、馬群がゆったり走行できるようにする**
4. **馬の横の馬名を外し、コース中央（内馬場）にリアルタイム電光掲示板（TOP 5表示）を新設**
5. **コース形状（ジオメトリ）と馬の走行軌跡を100%完全一致させ、コース外走行を解消**
6. **競馬場名称・特性を正式指定に更新（東京:左回り大箱 / 中山:右回り大箱 / 中京:左回り小回り / 小倉:右回り平坦）**
7. **全馬がゴールを通過するまで、ゴール済みの馬も自然に流して走行を継続する**
8. **走る馬のゼッケン色・番号色をJRA公式の枠色ルール（1枠白〜8枠桃）に完全対応**

### 3. レースシミュレーション・軌跡の改良（ゴール後の流し走行）

### 4. 2Dトラック描画・JRA枠色・内馬場電光掲示板の実装
#### [MODIFY] [src/gui/widgets/track_canvas.py](file:///Users/takashihorimatsu/Library/CloudStorage/GoogleDrive-thorimatsu@gmail.com/マイドライブ/h_sim/src/gui/widgets/track_canvas.py)
- **コース幅の拡大**:
  - `track_width` を 34 から 56 に大幅拡大。馬群の進路が広々と見えるように。
- **コース幾何学（ジオメトリ）の完全同期**:
  - `_get_track_geometry(w, h)` を新設し、2Dトラック描画・ゴール板描画・馬の座標計算（`_calc_horse_pos_world`）で寸分違わず完全に同じパラメータ（直線長、コーナー半径、センターライン）を使用。これにより「コース外を馬が走る」不具合を完全解消。
  - 大箱（直線長め・大半径）と小回り（コーナー急）のコース形状の反映。
- **JRA公式8枠制の枠色ロジックの実装**:
  - 頭数に応じた正確な枠番割り当て計算式 `get_jra_bracket(gate, total)`。
  - 1枠（白）、2枠（黒）、3枠（赤）、4枠（青）、5枠（黄）、6枠（緑）、7枠（橙）、8枠（桃）の配色。
  - コース上の各馬のゼッケン、および掲示板の番号プレートに適用。
- **内馬場の電光掲示板（LIVE TURF VISION）の実装**:
  - トラック中央の芝生エリアに、JRA大型ターフビジョン風の電光掲示板を美麗に描画。
  - 現在フレームのリアルタイム TOP 5（1位〜5位）の馬番（枠色付き）・馬名・先頭との差を表示。
  - 走る馬の頭上からは邪魔な馬名テキストを削除し、スッキリと見やすいゼッケンサークルのみを描画。
- **デフォルト視点を2Dに設定**。
