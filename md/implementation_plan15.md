# レースバランス改善（逃げ馬偏重の解消）および順位バー幅・スケール調整 実装計画

ユーザー様から以下の2点のご指摘をいただきました。
1. **「基本逃げ馬しか勝てない状況です。パラメータを見直してください。」**
2. **「レース画面下の順位バーですが横のスケールが長すぎて馬が消えてしまいます。バーの幅を調整してください。」**

本計画では、ゲームバランス（走破タイム確定アルゴリズムおよびリプレイ展開）とGUI表示（順位バーのスケールと全頭描画）の両面を根本から見直し、白熱したレース展開と快適な観戦UIを実現します。

---

## 課題の分析と原因

### 課題1: 逃げ馬偏重の原因
1. **走破タイム計算（`calculate_finish_time`）の脚質補正不足**:
   - 直線距離補正が `450m以上` または `320m以下` に限定されており、中山2000m外回りや阪神、京都など多くの標準コース（330〜440m）で脚質補正が一切効いていなかった。
   - 逃げ馬の頭数によるペース激化（ハイペースによる消耗）が存在せず、何頭逃げ馬がいてもバテずに逃げ切れていた。
   - 差し・追込馬の瞬発力（acceleration）による終盤の末脚（上がりタイム短縮）の恩恵が弱かった。
2. **リプレイの視覚的ペースプロファイル（`generate_replay_data`）の速度差不足**:
   - 終盤スパート（`p_spurt`）の速度倍率が、逃げ `0.985` に対し追込 `1.015` とわずか 3% しか差がなかった。
   - そのため、前半で逃げ馬が広げたリード（15〜20m）を、直線ラスト200mで差し・追込が縮められる距離がたったの 6m（約2.5馬身）にとどまり、視覚的にも「最初から最後まで逃げ馬が先頭のまま逃げ切る」展開になっていた。

### 課題2: 順位バーで馬が消える原因
- `src/gui/widgets/track_canvas.py` において、先頭からの表示距離レンジが `view_dist_span = 35.0m`（約14馬身分）に固定されていた。
- 18頭立てのレースでは先頭から最後方まで 60m〜100m以上離れるのが普通であるため、中団〜後方の馬（10番手以降）が `hx < sec_mid_x + 10` となって画面左端からフレームアウトし、完全に消えてしまっていた。

## 提案する改修内容

### 1. レースエンジン (`src/race/engine.py`) のパラメータ見直し
- **走破タイム計算（`calculate_finish_time`）**:
  - **ペース展開とスタミナ消費**:
    - 出走馬中の逃げ頭数を集計。逃げ馬が2頭以上の場合は「先行争い・ハイペース」となり、逃げ馬にスタミナ消耗ペナルティを付与。
    - 逃げ馬はスタミナ不足時に直線で失速しやすくなる。
  - **脚質ごとの適性ステータスを反映**:
    - 差し（BETWEEN）・追込（CLOSING）: `acceleration`（瞬発力）によるタイム短縮効果を強化し、直線での強襲・ごぼう抜きを再現。
    - 逃げ（ESCAPE）: 単騎逃げ（1頭）時はマイペースで有利だが、`speed` と `stamina` の両方が高水準でないと粘り切れないように調整。
  - **直線距離に応じた連続的なコース補正**:
    - 直線が長い東京・新潟等では差し・追込が有利、小回りの小倉・函館等では逃げ・先行が有利となるよう、直線長に応じた滑らかな補正曲線を導入。
- **リプレイ展開（`generate_replay_data`）**:
  - 各脚質のペースプロファイル（`p_start, p_mid, p_corner, p_spurt`）をリアル競馬の速度変化に適合:
    - **逃げ (ESCAPE)**: 前半快速（1.030）だが直線スパートは 0.945（粘り込むが脚色は鈍る）
    - **先行 (LEADING)**: 好位キープ（1.015）から直線 0.990（安定した押し切り）
    - **差し (BETWEEN)**: 中団待機（0.990）から直線 1.050（鋭い末脚で一気に差す）
    - **追込 (CLOSING)**: 後方待機（0.975）から直線 1.085（大外一気のごぼう抜き）
  - これにより、差し・追込馬が直線で豪快に逃げ馬を交わすドラマチックなレース展開を実現。

### 2. 順位バーの全馬表示スケール自動調整 (`src/gui/widgets/track_canvas.py`)
- **オートスケール（全頭収容）の導入**:
  - 現在の先頭馬と最後方馬の最大距離差（`max_behind_m`）を動的に算出し、`view_dist_span = max(90.0, max_behind_m + 15.0)` とすることで、どれだけ馬群が縦長になっても18頭全員がバー内に常に収まるようにする。
- **バー内部マージンの最適化**:
  - バーの左端・右端に適切なパディング（20px）を設け、アイコンがバーの枠線からはみ出したり途切れたりしないようクランプ。
  - 距離目盛（-10m, -20m, -40m, -60m, -80m）もスケールに合わせて見やすく配置。
