# Implementation Plan: リーディング・サイアーランキング機能拡張

リーディング各画面（騎手・調教師・馬主・生産牧場・サイアー）において、戦績（1着-2着-3着-着外）・重賞（G1-G2-G3）・代表馬（重賞勝ち現役馬・最大3頭）の表示機能、およびサイアーランキングにおける種牡馬クリック時の現役産駒一覧ダイアログ（賞金順表示＆馬詳細ダイアログ連携）を実装します。

## Proposed Changes

### 1. リーディング集計ロジック拡張 (`src/race/rankings.py`)
- `RankingManager` の各メソッド（`get_jockey_rankings`, `get_trainer_rankings`, `get_owner_rankings`, `get_breeder_rankings`, `get_sire_rankings`）を拡張：
  - 各カテゴリにおいて、1着・2着・3着・着外、および G1・G2・G3勝利数を正確に集計。
  - 当年（`is_career=False`）および通算（`is_career=True`）の集計に対応。
  - 各エンティティ（騎手・調教師・馬主・生産牧場・種牡馬）ごとの**代表馬（現役馬かつ重賞勝ち馬、G1勝利数・重賞数・賞金上位ベースで最大3頭）**のリストを取得するロジックを追加。重賞勝ちがない場合は空リスト（表示なし）とする。
- 種牡馬の現役産駒一覧を取得するメソッド `get_sire_progenies(sire_horse_id)` を追加（賞金降順）。

### 2. 種牡馬産駒一覧ダイアログ (`src/gui/views/sire_progeny_dialog.py` または `rankings_view.py`)
- 種牡馬の現役産駒一覧モーダルダイアログを作成：
  - タイトル: `種牡馬「〇〇」の現役産駒一覧`
  - 賞金順でテーブル表示（馬名、性齢、脚質、厩舎、馬主、戦績、主な勝ち鞍、獲得賞金）
  - 各行クリック／ダブルクリックで `HorseDetailDialog` を開き、その馬の詳細成績・血統を閲覧可能。

### 3. リーディング画面UI改修 (`src/gui/views/rankings_view.py`)
- テーブルカラム構成を刷新：
  - **騎手**: [順位, 騎手名, 所属, 区分, 戦績 [1-2-3-外], 重賞 [G1-G2-G3], 勝率, 獲得賞金, 代表乗鞍]
  - **調教師**: [順位, 厩舎名, 所属, 得意分野, 戦績 [1-2-3-外], 重賞 [G1-G2-G3], 勝率, 獲得賞金, 代表持ち馬]
  - **馬主**: [順位, 馬主名, 冠名, 戦績 [1-2-3-外], 重賞 [G1-G2-G3], 資金残高, 獲得賞金, 代表持ち馬]
  - **生産牧場**: [順位, 牧場名, 地域, 戦績 [1-2-3-外], 重賞 [G1-G2-G3], 資金残高, 生産賞金, 代表産駒]
  - **サイアー**: [順位, 種牡馬名, 系統, 種付料, 戦績 [1-2-3-外], 重賞 [G1-G2-G3], AEI, 獲得賞金, 代表産駒]
- 種牡馬名にクリックリンク（青字下線/ボタンスタイル）を設定し、クリック時に産駒一覧ダイアログを起動。

## Verification Plan

### Automated Tests
- `tests/test_rankings_refinements.py` を作成し、以下を検証：
  - 騎手・調教師・馬主・牧場・サイアーの戦績 [1-2-3-外] 及び 重賞 [G1-G2-G3] が正しく集計されること。
  - 代表馬が「現役馬かつ重賞勝ち馬」のみから最大3頭選ばれ、重賞勝ちがない場合は表示されないこと。
  - 種牡馬の現役産駒取得ロジックが賞金順で正しく返されること。

### Manual Verification
- GUIを起動し、5大リーディング各タブの表示確認。
- サイアーランキングで種牡馬名をクリックし、現役産駒一覧ダイアログが開き、そこから各馬の詳細ダイアログに遷移できることを確認。
