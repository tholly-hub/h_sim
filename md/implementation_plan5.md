### ステップ 2: 【Phase 2】交配・遺伝アルゴリズムの実装 (`src/core/genetics.py`)
仕様書の3層遺伝モデルを厳密に実装します。

1. **ミオスタチン（MSTN）遺伝子継承**:
   - メンデルの法則に従い、父馬から1アレル、母馬から1アレルをランダムに継承。
   - `C/C`（スプリンター）、`C/T`（マイラー・中距離）、`T/T`（ステイヤー）。
2. **ポリジーン遺伝（5大基本能力）**:
   - 最高速度、持久力、瞬発力、気性、耐久力の各パラメータ。
   - 定義式: $P_{child} = \mu + \frac{1}{2}h^2(P_{sire}-\mu) + \frac{1}{2}h^2(P_{dam}-\mu) + \epsilon$
     - 平均固定値 $\mu = 50.0$（能力インフレ防止）
     - 遺伝率 $h^2 = 0.40$
     - 環境分散 $\epsilon \sim \mathcal{N}(0, \sigma^2)$（ランダムな変異）
3. **母系遺伝（ミトコンドリアDNA・母性効果）**:
   - 母馬の「心肺機能・底力（maternal_vitality）」を高い相関で継承（低確率の突然変異あり）。
4. **成長型とピーク年齢の継承**:
   - 早熟（ピーク 2.5〜3.5歳） / 普通（ピーク 3.5〜5.0歳） / 晩成（ピーク 5.0〜6.2歳）の親からの確率的遺伝。
5. **インブリード（近親交配）判定**:
   - 5代血統表を走査し、父方・母方の共通祖先を抽出して血量を算出（例: 3×4 = 18.75% の「奇跡の血量」）。
   - 適度なインブリードによる特定能力の強調ボーナスと、過度な近親交配（血量25%超）による気性悪化・耐久力低下ペナルティ。

### ステップ 3: 【Phase 2】生産・受胎サイクル & 自動命名 (`src/core/breeding.py`)
1. **年間種付け処理**:
   - 全50牧場の繁殖牝馬（約600頭）と種牡馬（60頭）のマッチング。
   - 1頭の種牡馬あたりの年間種付け上限: **最大30頭**。
   - 自場繋養種牡馬の優先、または評判・相性に応じた種牡馬選定。
2. **幼駒誕生（年間約500頭）**:
   - 受胎率（約80〜85%）により、年間約500頭の0歳当歳馬が誕生（牡牝比率 50:50）。
   - 自動命名: 所有馬主の冠名（Prefix）＋純粋カタカナ単語辞書からのユニーク命名。
3. **サイアーライン保護ロジック**:
   - 系統の断絶を防ぐため、産駒数が減少し断絶寸前の父系ラインの種牡馬には優先種付けや後継種牡馬の確保を行う。

### ステップ 4: 【Phase 2】世代交代・加齢・引退サイクル (`src/core/lifecycle.py`)
1. **年間カレンダー進行（年末処理）**:
   - 全頭の年齢加齢（+1歳）。
   - ピーク年齢を過ぎた古馬の能力減衰（毎年5〜10%の能力低下）。
2. **競走馬の引退判定**:
   - **8歳末強制引退**: 8歳を終えた現役馬は自動的に現役引退（9歳以上は現役不可）。
   - **早期繁殖入り**: G1勝ち馬等の有力馬は4〜5歳で早期引退し、種牡馬（牡馬）・繁殖牝馬（牝馬）へ昇格。
   - **3歳未勝利足切り**: 3歳秋時点で未勝利の馬の引退（※レース実装後に連動）。
3. **繁殖牝馬の引退判定**:
   - 18〜20歳到達、または受胎能力低下に伴い繁殖引退。
4. **関係者の世代交代（以前策定した枠組みの統合）**:
   - **騎手**: 30年間（50歳）で現役引退。美浦・栗東で各1名（計2名）の新人騎手（20歳）が毎年デビューし、定員60名（美浦30・栗東30）を完全維持。
   - **厩舎**: 80歳で定年引退。引退した騎手（49〜50歳）が厩舎を引き継ぎ、定員60厩舎を完全維持。
5. **牧場・馬主の動的分化**:
   - 活躍馬輩出による牧場の評判・資金上昇、受け入れ枠の拡張（上限100頭）。
   - 所属頭数が減少した牧場への近隣牧場からの譲渡（「種牡馬1・繁殖牝馬1」の下限維持）。
