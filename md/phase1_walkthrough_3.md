# 【Phase 1】競馬シミュレーションエンジン環境構築・データ生成 実装完了レポート (第3版)

ユーザー様のご要望に基づき、**「馬主名（苗字＋会社名）および現存名と被らない連想オリジナル冠名」** の仕様改定を実施・検証完了しました。

---

## 1. 今回の改定内容

### ① 馬主名の命名ルール（苗字＋会社名）
- 馬主名をすべて **`[日本の苗字] + [会社種別（商事、建設、商会、ホールディングス、重工、不動産など）]`** の形式に統一しました。
  - 例: `鈴鹿建設`, `桐谷商事`, `蓮見商会`, `神崎ホールディングス`, `黒川重工`, `白石物産`, `藤森不動産`, `青柳工業`, `橘実業`, `峰岸興業` ... 全100社

### ② 冠名（Prefix）の独自性と連想ルール
- 実在・現存する著名馬主の冠名（サトノ、トウカイ、シンボリ、メジロ、ダイワ、エア、ナリタ、アグネス、テイエム、ゴールド、ディープ、キタサン、ロード、エイシン、スマート、アドマイヤ、メイショウ、マチカネ、ウイン、コスモ、ショウナン、ヒシ、カレン、ゼンノ、ミッキー、ダノン等）との重複を徹底排除。
- 各馬主の苗字の音や漢字の持つ意味から自然に連想される **完全オリジナルのカタカナ2〜4文字の冠名（100通りすべて一意）** を設定しました。
  - 鈴鹿建設 ➔ 冠名: **【ベルカ】** (鈴: Bell + 鹿)
  - 桐谷商事 ➔ 冠名: **【キリヤ】** (桐谷)
  - 蓮見商会 ➔ 冠名: **【ハスミ】** (蓮見)
  - 神崎ホールディングス ➔ 冠名: **【カンザキ】** (神崎)
  - 黒川重工 ➔ 冠名: **【クロカワ】** (黒川)
  - 白石物産 ➔ 冠名: **【シライシ】** (白石)
  - 藤森不動産 ➔ 冠名: **【フジモリ】** (藤森)
  - 氷室製薬 ➔ 冠名: **【ヒムロ】** (氷室)
  - 剣持グループ ➔ 冠名: **【ケンモチ】** (剣持)
  - 霞総業 ➔ 冠名: **【カスミノ】** (霞)

### ③ 自動生成される競走馬名
- `[馬主の冠名] + [単語/パーツ]` により、すべて **JRA競走馬登録基準のカタカナ2〜9文字以内** で命名。
  - 例: `ケンモチオー` (6文字), `ヒムロシャドウ` (7文字), `キリヤロードスター` (9文字), `オギノソウル` (6文字), `カスミノナイト` (7文字)
