# 【実装計画】番組表開催場の適正化・初期現役馬クラス適正化・ダッシュボード競馬場別タブ化

## 概要
ユーザーからのご指摘に基づき、以下の3点の改善・修正を実施します：
1. **初期現役馬のクラス・戦績配分の適正化**:
   - データベース初期化時に `with_careers=True` をデフォルト化し、3〜6歳馬に自然なクラス（オープン、3勝C、2勝C、1勝C、未勝利）と収得賞金を付与。6月1週（21週）時点で3歳未勝利戦に異常な頭数が殺到する問題を根本解消します。
2. **年間レース番組表（2〜3場開催）の完全整合**:
   - 安土城S（21週・阪神）をはじめ、全48週の重賞・リステッド・特別戦・条件戦の `track_id` を、各週の開催競馬場 `weekly_tracks`（2〜3場）と完全に一致させます。
   - すべての開催場において複数レース（未勝利・1勝・2勝・3勝・重賞/リステッド等、各場5〜8レース程度）がバランスよく配置され、1レースのみ単独開催される競馬場をゼロにします。
3. **ダッシュボード「今週の開催」の競馬場別タブ表示化**:
   - ダッシュボード2行目を `QTabWidget` による競馬場別タブ（例: `[東京競馬場] [阪神競馬場] [大井競馬場]`）に変更。
   - 各タブ内にその競馬場で行われるレース一覧（未勝利→新馬→1勝→2勝→3勝→L/OP→G3→G2→G1順）を表示し、選択されたレースの出走馬表（3行目）へスムーズに連携します。

---

## 提案される変更内容

### 1. `src/generators/initializer.py`
- `generate_initial_population` および `initialize_all` の `with_careers` 引数のデフォルト値を `True` に変更。
- 3歳馬（350頭）について、6月1週（春競馬終了時点）に見合うよう、約半数以上が1勝クラス〜重賞馬として勝ち上がり、残りの未勝利馬が夏競馬で無理なく出走できるように実績を配分。
- 4〜6歳馬についても、オープン、3勝クラス、2勝クラス、1勝クラスに自然に分布させ、各条件戦の頭数を適正化。

### 2. `src/race/annual_program.py`
- `weekly_tracks` と、重賞（`major_races`）・リステッド（`LISTED_TITLES`）・条件戦（3勝C/2勝C/1勝C/新馬/未勝利）の競馬場 `track_id` を全週突合・整合。
  - 例: 21週の安土城Sを `HANSHIN` に修正。
  - その他、開催場外に設定されている重賞・リステッドの `track_id` を `weekly_tracks` に合わせて修正。
- 条件戦生成ループ（3勝C/2勝C/1勝C/新馬/未勝利）において、その週の各開催場（2〜3場）に均等にレースが配分されるように調整。

### 3. `src/gui/views/dashboard_view.py`
- 2行目の「今週の開催レース一覧」UIを `QTabWidget`（`tabs_tracks`）に変更。
- 各週の開催競馬場（例: 東京、阪神、大井）ごとにタブを作成。
- 各タブ内に `QTableWidget`（レース一覧テーブル）を配置。
- レース一覧は指定順（未勝利→新馬→1勝→2勝→3勝→L/OP→G3→G2→G1）でソートして表示。
- タブ切り替え時やセル選択時に、選択されたレースの出走馬表（3行目）を即時更新。
