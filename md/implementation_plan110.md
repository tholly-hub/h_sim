# 動的種付け料システムの導入およびオッズ分散・メリハリ改善計画

## 概要
1. **動的種付け料システムの実装**:
   - **新規種牡馬の初年度種付け料**: 現役時代のG1勝利数、重賞勝利数、通算獲得賞金、基礎能力値に応じた適正な初年度種付け料を自動算定。
   - **産駒活躍による年次改定**: 年末の年進行時に、当年の産駒獲得賞金（サイアーランキング）、産駒G1/重賞勝利数、種付け需要等に基づき毎年の種付け料を自動増額・減額改定。
2. **オッズ計算の分散・メリハリ強化（全頭10倍以内問題の解消）**:
   - 現状のSoftmax温度パラメータ（temp=12.0）が高すぎて全馬の確率が平滑化され、全頭4〜8倍に収束していた問題を修正。
   - 温度パラメータを適正値（temp=4.5〜5.0）に調整し、能力・適性・実績差をスコアへ適切に反映することで、圧倒的1番人気（1倍台）、対抗（3〜7倍）、中穴（10〜25倍）、大穴（30〜100倍超）のリアルなオッズ体系を実現。

---

## 提案する変更内容

### 1. 競馬シミュレーションエンジン (`src/race/engine.py`)
- `calculate_odds` の改善:
  - Softmax温度を `temp = 5.0` に調整。
  - 馬場適性不一致時の減点を適正化。
  - 能力・実績（勝率・重賞数）・調子の反映比重を強化し、実力馬はより低オッズ、劣後馬はより高オッズとなるよう分散を拡大。

### 2. ライフサイクル管理エンジン (`src/core/lifecycle.py`)
- **新種牡馬の初年度種付け料算定ロジック**:
  - ベース: 100万円
  - G1勝利ボーナス: 1勝につき +150万〜250万円（クラシック・王道G1加点）
  - G2/G3勝利ボーナス: G2 +50万円, G3 +30万円
  - 生涯獲得賞金ボーナス: 1億円ごとに +40万円
  - 基礎能力ボーナス: スピード/スタミナが優秀な場合加点
  - 例: G1 3勝・賞金8億の名馬 -> 1,000万〜1,500万円、重賞1勝馬 -> 200万〜300万円
- **産駒成績に応じた種付け料の年次動的改定ロジック (`_update_sire_stud_fees`)**:
  - 年末の年進行時に全稼働種牡馬を対象に実行。
  - 産駒の当年獲得賞金、G1/重賞勝利数、出走頭数を集計。
  - 産駒G1勝利またはサイアーリーディング上位（Top5）: +100万〜300万円
  - 産駒重賞勝利または獲得賞金好調: +30万〜50万円
  - 産駒成績不振（当年勝利数極小、賞金低迷）: -20万〜50万円（下限50万円、上限3,000万円）
