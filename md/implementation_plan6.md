# 【追加実装計画】厩舎スキル成長・所属騎手制度 & 騎手キャリア・成長曲線・調教助手世代交代システム

ユーザー様からのご指示に基づき、厩舎（調教師）および騎手（Jockey）のライフサイクル、スキル成長、所属/フリー制度、および調教助手・世代交代承継システムを大幅に強化・実装します。

---

## ユーザー確認事項（User Review Required）

> [!IMPORTANT]
> **主な仕様決定事項**:
> 1. **騎手総数の拡大と定員維持**:
>    - 60厩舎すべてに所属騎手を配備し、かつトップ騎手がフリーとして活動できるよう、**現役騎手の定員を 美浦45名 / 栗東45名（計90名）** に設定します（従来60名から拡張）。
>    - 引退人数と同数の新人騎手（18歳）が毎年デビューし、定員90名を常に一定維持します。
> 2. **騎手デビュー・所属・フリー化の条件**:
>    - **デビュー**: 18歳。必ずいずれかの厩舎の「所属（専属）騎手」としてスタート。
>    - **フリー化条件**: 「通算100勝以上 かつ G1 1勝以上」 または 「G2 3勝以上」 または 「G3 5勝以上」 を達成した騎手はフリー騎手に転向可能。
> 3. **騎手の成長曲線と40歳ピーク・体力低下**:
>    - 40歳前後（早熟: 36歳、普通: 40歳、晩成: 43歳）を境に、経験値・技術（skill, start_dash, temperament_handling）は向上し続ける一方、体力（stamina）および直線の追い（drive）が徐々に減退。
> 4. **騎手引退・調教助手転身 & 厩舎承継ルール**:
>    - **引退条件**: 5年目/10年目/20年目の成績足切り、50歳以上での年間成績不振、または60歳定年。
>    - **調教助手転身**: 50歳未満で引退した騎手は所属厩舎の「調教助手」に就任（定年50歳）。
>    - **厩舎承継（調教師80歳定年時）**:
>      1. 引退する有力フリー騎手が存在する場合、調教助手が不在の厩舎を優先承継（元騎手実績に応じた厩舎スキル初期ボーナス付与）。
>      2. それ以外は、自厩舎の所属調教助手（複数名の場合は現役時代実績最上位者）が厩舎を承継。
>      3. 候補がいない場合は新規調教師（50歳）が就任。
> 5. **厩舎スキル向上**:
>    - 調教師スキルは「開業年数」「通算勝数」「重賞/G1勝利実績」により年々向上し、**生涯減少・減衰しない**。

## 実装計画

### 1. データベース・スキーマの拡張 (`src/db/schema.py`)
- **`trainers` テーブル**:
  - `skill_level REAL DEFAULT 50.0`: 調教師スキル（開業年数・成績で向上、減少しない）
- **`jockeys` テーブル**:
  - `growth_type TEXT DEFAULT 'standard'`: 成長型（`early`, `standard`, `late`, `persistent`）
  - `is_free INTEGER DEFAULT 0`: 0=厩舎所属, 1=フリー
  - `trainer_id INTEGER NULL`: 所属厩舎ID（フリーの場合はNULL）
  - `experience REAL DEFAULT 0.0`: 経験値
  - `stamina REAL DEFAULT 50.0`: 体力パラメータ
- **`assistant_trainers` テーブル（新規追加）**:
  - `assistant_id INTEGER PRIMARY KEY AUTOINCREMENT`
  - `jockey_id INTEGER NOT NULL`: 元騎手ID
  - `trainer_id INTEGER NOT NULL`: 所属厩舎ID
  - `name TEXT NOT NULL`
  - `age INTEGER NOT NULL`
  - `career_wins INTEGER NOT NULL`
  - `g1_wins INTEGER NOT NULL`
  - `is_active INTEGER DEFAULT 1`: 1=現役調教助手 (〜50歳), 0=定年退職

---

### 2. データモデルの更新 (`src/models/trainer.py`, `src/models/jockey.py`)
- **`Trainer` モデル**:
  - `skill_level` プロパティの追加。
  - スキル向上計算ロジック（年数 + 勝利数 + 重賞勝利に応じた成長）。
- **`Jockey` モデル**:
  - `growth_type`, `is_free`, `trainer_id`, `experience`, `stamina` フィールド追加。
  - 年齢・成長曲線に応じた能力変動計算（技術上昇 ＆ 40歳以降の体力/推進力低下）。
  - フリー化資格判定プロパティ（`can_become_free`）。

---

### 3. 初期生成と騎手定員拡張 (`src/generators/initializer.py`, `src/management/jockey_manager.py`)
- **初期騎手生成**:
  - 美浦45名 / 栗東45名（計90名）を生成。
  - 全60厩舎に1名ずつ所属騎手を均等配備。残り（約30名）は実績十分なフリー騎手または追加所属として配備。
  - デビュー年齢を 18歳 に設定。
- **新人騎手補充ロジック**:
  - 毎年引退した人数分だけ、18歳の新人騎手を生成（初期は必ず所属騎手不足の厩舎に専属所属）。

---

### 4. 厩舎・騎手管理および起用ロジック (`src/management/jockey_manager.py`, `src/management/stable_manager.py`)
- **騎手起用ロジック**:
  - 平場・一般条件戦: 自厩舎の所属騎手を最優先起用。
  - 重賞・有力馬（オープン/重賞）: 自厩舎の所属騎手が中堅以下の場合は、有力なフリー騎手（トップジョッキー）を優先選定可能。
- **フリー転向判定**:
  - 年末処理で条件（通算100勝+G1または重賞多数）を満たした所属騎手はフリーへ転向。

---

### 5. ライフサイクル・世代交代・調教助手承継の実装 (`src/core/lifecycle.py`)
- **年進行ステップの強化**:
  1. **騎手の能力推移**:
     - 成長曲線に応じた技術成長 ＆ 40歳以降の体力・推進力減退。
  2. **調教師のスキル向上**:
     - 開業年数・通算勝利・重賞実績に基づきスキル値を加算（減少なし）。
  3. **騎手の多段階引退判定**:
     - 5年目/10年目/20年目の成績不振、50歳以上の低迷、60歳定年。
  4. **調教助手への転身 & 調教助手定年（50歳）**:
     - 50歳未満で引退した騎手は所属厩舎の調教助手に就任。50歳で調教助手定年。
  5. **厩舎世代交代（80歳定年）**:
     - 引退フリー騎手（有力） ＞ 自厩舎調教助手（現役成績順） ＞ 新規調教師 の優先順で承継。
     - 有力元騎手が調教師となった場合、現役実績に応じた初期厩舎スキルボーナスを付与。
  6. **新人騎手（18歳）のデビュー**:
     - 引退人数と同数の新人騎手をデビューさせ、所属騎手不在厩舎へ配属。

## 検証計画（Verification Plan）

### 1. 自動テストの拡充 (`tests/test_trainer_jockey_system.py`)
- **初期生成テスト**:
  - 騎手定員が90名（美浦45/栗東45）であること。
  - 全60厩舎に所属騎手が配備されていること。
  - デビュー年齢が18歳であること。
- **スキル成長・体力減衰テスト**:
  - 厩舎スキルが開業年数とともに向上し、決して減少しないこと。
  - 騎手の40歳以降で技術（skill）が向上しつつ体力（stamina/drive）が減衰すること。
- **フリー化・多段階引退・調教助手承継テスト**:
  - 実績を満たした騎手がフリー化すること。
  - 引退騎手が調教助手として所属厩舎に入り、80歳調教師定年時に厩舎を引き継ぐこと。
  - 有力フリー騎手引退時に調教助手不在厩舎を引き継ぎ、厩舎スキルボーナスが付与されること。
- **10年〜20年連続年進行テスト**:
  - 騎手定員90名、厩舎数60が何年経過しても完全維持されること。
