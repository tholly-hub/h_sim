## 3. 種付けルールの高度化（厩舎・年齢・実績・血統ドラフト選定）

種牡馬は年間最大種付け頭数 **30頭**（仕様制限）のため、人気種牡馬には多数の繁殖牝馬からオファーが集まります。以下の優先度スコアリングにより、リアルな種付け受託ドラフトを実施します。

### 優先度スコア算出式 (Priority Score)
各繁殖牝馬 $i$ が種牡馬 $j$ に申し込む際の優先度：
$$\text{PriorityScore} = S_{\text{same\_trainer}} + S_{\text{trainer\_rank}} + S_{\text{youth}} + S_{\text{mare\_quality}} + S_{\text{same\_farm}} - P_{\text{inbreeding}}$$

1. **同厩舎出身優先 ($S_{\text{same\_trainer}}$)**:
   - 繁殖牝馬の現役時所属厩舎と、種牡馬の現役時所属厩舎が同一の場合：**+30点**（同厩舎の絆・ライン）
2. **所属厩舎の優秀度 ($S_{\text{trainer\_rank}}$)**:
   - 繁殖牝馬の所属厩舎のスキルレベルや当年・通算勝利数上位：**最大 +25点**（上位厩舎出身馬は産駒の預託先としても種牡馬側から大歓迎される）
3. **繁殖牝馬の若さ ($S_{\text{youth}}$)**:
   - 受胎率・活力が高い若年牝馬を優遇：
     - 5〜8歳：**+20点**（最優遇）
     - 9〜12歳：**+12点**
     - 13〜15歳：**+5点**
     - 16歳以上：**0点**（高齢減点なし）
4. **繁殖牝馬の実績・ランキング上位 ($S_{\text{mare\_quality}}$)**:
   - G1勝ち馬：**+35点**、重賞勝ち馬：**+20点**、収得賞金・総合能力値（Speed+Stamina+Accel）：**最大 +20点**
5. **自家生産優先 ($S_{\text{same\_farm}}$)**:
   - 牝馬の繋養牧場と種牡馬の繋養牧場が同一の場合：**+25点**（自家枠確保）
6. **血統考慮・近交危険度ペナルティ ($P_{\text{inbreeding}}$)**:
   - 4代血統表でのインブリード血量が **18.75%超（危険水域）** の組み合わせは **大幅減点または除外**。
   - 奇跡の血量（18.75% = 3×4）や適性補完（MSTN短距離×長距離など）にはボーナス。

### 【より優れた方法の提案：ドラフト・第3希望スライド制】
- 各繁殖牝馬は、牧場の資金力と血統相性を考慮して「第1希望」「第2希望」「第3希望」を選択。
- 種牡馬ごとにオファーを集約し、**上記優先度スコア上位30頭** を受託確定。
- 溢れた牝馬は第2希望、第3希望へと自動スライドし、受託枠が余っている優良種牡馬へと安全にマッチング。
- これにより、一部のトップ種牡馬に注文が殺到しても確実に全繁殖牝馬が良質な相手と配合されます。
