# 競馬シミュレーション 総合機能強化 & バランス改善 実装計画

ユーザー様からいただいた6項目の修正・機能追加を実施します。

---

## 1. 2歳ダート路線の拡充 & 全日本2歳優駿トライアル追加

### 課題
現状、2歳ダート路線は新馬・未勝利を勝ち上がった後の番組が不足しており、12月の全日本2歳優駿（G1）へ向けたステップレースが整備されていません。

### 改修内容 (`src/race/annual_program.py`, `src/race/program.py`)
- **カトレアステークス（リステッド）**: 11月第43週 / 東京ダート1600m / 2歳混合 / トライアル（1着馬に全日本2歳優駿の優先出走権）
- **JBC2歳優駿（G3/Jpn3）**: 11月第41週 / 門別(MORIOKA/地方) ダート1800m / 2歳混合 / トライアル（1〜2着馬に全日本2歳優駿の優先出走権）
- **兵庫ジュニアグランプリ（G2/Jpn2）**: 11月第44週 / 園田(FUNABASHI/地方) ダート1400m / 2歳混合 / トライアル（1〜3着馬に全日本2歳優駿の優先出走権）
- これらのレースを全日本2歳優駿の公式トライアルとして年間番組表に組み込みます。

## 2. G1トライアル体系の本格導入 & 優先出走権獲得馬の温存制御

### 課題
2歳重賞や各路線の重賞で同じ有力馬が何度も短期間に出走する傾向があり、トライアルで優先出走権を得た馬が温存されずに連戦してしまう。

### 改修内容 (`src/race/annual_program.py`, `src/race/entry.py`)
1. **トライアルレースの名称規則**:
   - G1レースのおよそ6週前までに開催される重賞・リステッドレースに対し、レース名に `[[G1レース名]トライアル]` を付与。
   - （例: `弥生賞ディープ記念 [皐月賞トライアル]`, `チューリップ賞 [桜花賞トライアル]`, `カトレアステークス(L) [全日本2歳優駿トライアル]` 等）
2. **優先出走権の付与頭数制限**:
   - **G2**: 1〜3着（最大3頭）
   - **G3**: 1〜2着（最大2頭）
   - **リステッド (L)**: 1着（最大1頭）
   - ※各G1への優先出走権合計が8頭（フルゲート上限）を超えないように設計。
3. **優先出走権獲得馬の温存（出馬制限）**:
   - 対象G1の優先出走権を獲得した馬は、**そのG1が開催されるまで他のトライアルレースや重賞・条件戦への出走を禁止（温存）**します。
   - 4着以下（優先出走権を逃した馬）は、次回以降のトライアルレースや条件戦に何度でも出走可能です。
4. **G1レースの出走選定**:
   - 優先出走権保持馬（最大8頭）を最優先で出走。
   - 8頭に満たない枠は、コース適性（芝/ダート、距離適性）を鑑みながら、収得賞金・獲得賞金上位順に出走枠を割り当てます。

## 3. レース中の馬の重なり防止（前後・左右判定の厳格化）

### 課題
2Dレースリプレイにおいて、馬群が密集した際に前後・左右の馬体が重なってしまう。

### 改修内容 (`src/race/engine.py`, `src/gui/widgets/track_canvas.py`)
1. **前後・左右クリアランスの拡大**:
   - 前後判定範囲を 2.6m から **3.8m** に拡大。
   - 横方向の安全クリアランス（`min_clearance`）を 1.30m から **2.0m** に拡大。
   - コース幅（30.0m）をフルに活用し、前壁を検知した際のスムーズな内外進路選択とペア間反発分離パスを強化。
2. **描画レイヤーの最適化**:
   - 描画スケール・シャドウ・馬体サイズの描画比率を調整し、並走時にも接触・重なりが生じないようにします。

## 4. 過去レース成績の日付フォーマット改修 & 降順（最新順）ソート

### 課題
1. 過去のレース履歴の日付表示が `1年 21週` となっており、月が含まれていない。
2. レース履歴テーブルが古い順（昇順）で表示されており、直近のレースが見づらい。

### 改修内容 (`src/gui/views/horse_detail_dialog.py`)
- フォーマットを **`[****]年/[**]月/[*]週`** 形式に統一（例: `0001年/06月/1週`）。
- レース履歴のクエリおよび表示順を **`ORDER BY r.year DESC, r.week DESC`（降順・最新順）** に変更し、直近のレースが最上段に表示されるように改修。

## 5. レース画面HUDのオッズ・馬名見切れ防止

### 課題
画面下部HUDの右セクション（上位3頭リール表示）で、長い馬名の場合に単勝オッズ（倍率）が見えなくなる。

### 改修内容 (`src/gui/widgets/track_canvas.py`)
- 右セクションの表示幅（`sec_right_w`）を 380px から **450px** に拡大。
- 馬名表示領域を 165px から **220px** に拡大し、文字サイズと配置を最適化。
- オッズ表示領域（幅 75px）を右端に独立固定し、馬名と絶対に干渉・重複しないレイアウトに変更。

## 6. コース適性・騎手スキルを織り込んだオッズ計算の再設計

### 課題
単勝オッズ1倍台の馬が簡単に負けるなど、オッズと実際の勝率・能力に乖離がある。

### 改修内容 (`src/race/engine.py`)
- 単なる基礎能力（スピード・瞬発力・スタミナ）だけでなく、以下の要素を包括した「**レース総合走破期待値（Expected Race Power）**」を算出：
  1. **馬場適性（芝・ダート適合度）**: 不適性馬場なら大幅減点。
  2. **距離適性（MSTNおよび適性レンジ合致度）**: 距離乖離ペナルティを反映。
  3. **騎手総合力**: `skill` だけでなく `drive`、`experience`、フリー騎手補正をフル反映。
  4. **調子・気性安定度**: 気性難によるブレを織り込み。
- Softmax の温度パラメータおよびオッズマッピングを最適化し、真の実力馬に適正な人気（1.5倍〜2.5倍等）を付与し、人気馬の勝率信頼性を向上。
