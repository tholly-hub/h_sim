# リーディング機能 & サイアーランキング機能拡張 ウォークスルー

## 概要
リーディング画面（騎手・調教師・馬主・生産牧場・サイアー）において、戦績（1着-2着-3着-着外）・重賞（G1-G2-G3）・代表馬（重賞勝ち現役馬・最大3頭）の表示機能、およびサイアーランキングにおける種牡馬クリック時の現役産駒一覧ダイアログ（獲得賞金順表示 & 馬詳細ダイアログ連携）を実装しました。

---

## 変更内容

### 1. リーディング集計モジュール (`src/race/rankings.py`)
- **戦績の内訳集計**:
  - `win_1`（1着）, `win_2`（2着）, `win_3`（3着）, `win_out`（着外）を正確に集計。
  - `g1_cnt`（G1勝）, `g2_cnt`（G2勝）, `g3_cnt`（G3勝）をそれぞれ集計。
  - 当年（`is_career=False`）および通算（`is_career=True`）の切り替えに対応。
- **代表馬の抽出ロジック**:
  - 現役馬（`is_active = 1`）かつ重賞勝ち（G1/G2/G3勝 > 0）の馬のみを対象とし、G1勝利数降順・重賞数降順・賞金降順で最大3頭抽出。
  - 重賞勝ちがない場合は非表示（`"-"`）。
- **種牡馬現役産駒取得**:
  - `get_sire_progenies(sire_horse_id)` を追加。該当種牡馬の現役産駒を総獲得賞金降順で取得。

### 2. 種牡馬産駒一覧ダイアログ (`src/gui/views/sire_progeny_dialog.py`)
- 種牡馬名をクリックした際に表示されるモーダルダイアログを新規作成。
- カラム構成: `[馬名, 性齢, 脚質, 所属厩舎, 馬主, 戦績, 重賞(G1/G2/G3), 主な勝ち鞍, 総獲得賞金]`
- 行クリックまたはダブルクリックで、既存の競走馬詳細ダイアログ（`HorseDetailDialog`）を開き、血統や過去成績をシームレスに閲覧可能。

### 3. リーディング画面UI (`src/gui/views/rankings_view.py`)
- 5大リーディング各テーブルの表示カラムを新仕様に更新：
  - **騎手**: 順位 / 騎手名 / 所属 / 区分 / 戦績 [1-2-3-外] / 勝率 / 重賞 [G1-G2-G3] / 獲得賞金 / 代表乗鞍
  - **調教師**: 順位 / 厩舎名 / 所属 / 得意分野 / 戦績 [1-2-3-外] / 勝率 / 重賞 [G1-G2-G3] / 獲得賞金 / 代表持ち馬
  - **馬主**: 順位 / 馬主名 / 冠名 / 戦績 [1-2-3-外] / 重賞 [G1-G2-G3] / 資金残高 / 獲得賞金 / 代表持ち馬
  - **生産牧場**: 順位 / 牧場名 / 地域 / 戦績 [1-2-3-外] / 重賞 [G1-G2-G3] / 資金残高 / 生産賞金 / 代表産駒
  - **サイアー**: 順位 / 種牡馬名 (産駒一覧) / サイアーライン / 種付料 / 戦績 [1-2-3-外] / 重賞 [G1-G2-G3] / AEI / 獲得賞金 / 代表産駒
- サイアーランキングの種牡馬名セルにリンクスタイル（🔗 種牡馬名）を適用し、クリックで産駒ダイアログを起動。
