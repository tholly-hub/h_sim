# レース結果・ハロン棒・オッズ・UI視認性向上 実装計画書

ユーザー様からの以下の5点のご要望に対応するための実装計画です。

1. **レース結果の着差（margin）の定義変更**:
   - 従来の「1着との差」から、**「一つ前の順位の馬（前走馬）とのタイム差」**による着差表現へ変更（1着は `-`、2着は1着との差、3着は2着との差、4着は3着との差...）。
2. **順位バーの丸数字拡大**:
   - 下部順位バーの馬番ゼッケン円形アイコンおよび数字フォントを拡大し、視認性を大幅に向上。
3. **ハロン棒のリアル表示（コース上および順位バー）**:
   - 添付画像（`media_1789532815375.png`）のデザインを忠実に再現：
     - 白い円形看板（縁取り付き）
     - 看板中央の赤い太文字の数字（サンセリフ・太字）
     - ポール支柱：赤と白のボーダーストライプ
   - 1ハロン＝200m。残り距離に応じて数字がカウントダウン（例：2000mレースではスタート時10、残り800m=4、残り400m=2、残り200m=1）。
   - **コース上**: 各ハロン地点の内ラチ沿いに添付画像準拠のハロン棒標識をリアルに描画。
   - **順位バー上**: 順位バー内または上部に各ハロン地点マーカーおよび現在の残りハロン看板を直感的に配置。
4. **上がり3ハロン（あがり3F）タイムの計算・表示**:
   - 各馬のラスト600m通過からゴールまでの所要時間を算出し、レース結果表に「上がり3F（例: 34.2）」として追加。
5. **馬の能力に応じたオッズ（単勝オッズ）の算出・表示**:
   - 出走各馬の総合能力値（スピード・スタミナ・瞬発力・調子・騎手能力・適性等）から確率モデル（Softmax）を用いて勝率を算出。
   - 控除率（JRA準拠の払戻率約80%）を適用し、リアルな単勝オッズ（例: 2.1倍〜145.8倍）を自動算出。
   - レース中HUD（右側上位馬テロップ）およびレース結果表（確定着順）にオッズを表示。

### 2. レースエンジン・オッズ・計算層
#### [MODIFY] [engine.py](file:///Users/takashihorimatsu/Library/CloudStorage/GoogleDrive-thorimatsu@gmail.com/マイドライブ/h_sim/src/race/engine.py)
1. **着差（margin）計算の改修**:
   - 1着は `margin = "-"`。
   - 2着以降は、1つ前の順位の馬（`sorted_horse_ids[rank - 2]`）のゴールタイムとの差分 `prev_diff = round(f_time - prev_time, 2)` を取り、`calculate_margin(prev_diff)` で着差（ハナ、クビ、アタマ、1/2、1 1/4、大差など）を算出。
2. **能力ベースのオッズ算出ロジック (`calculate_odds`)**:
   - 各出走馬の能力（スピード 45%、瞬発力 25%、スタミナ 20%、調子係数、騎手技量ボーナス 10%）から実効レーティングを算出。
   - レーティングを Softmax 関数で勝率分布 $P_i$ に変換。
   - 還元率 80%（控除率 20%）を適用し、$\text{Odds}_i = \max(1.1, \min(999.9, \text{round}(0.80 / P_i, 1)))$ を算出。
3. **上がり3ハロン（ラスト600m）タイムの正確な算出**:
   - シミュレーション内で各馬が残り600m（$D - 600$）地点を通過した時刻 $t_{600}$ を検出し、ラスト3Fタイム $t_{\text{last3f}} = \text{ゴールタイム} - t_{600}$ を算出。
   - `replay_frames` の各フレームの馬データにも `odds` を格納。
