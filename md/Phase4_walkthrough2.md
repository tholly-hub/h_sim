# 修正内容のウォークスルー: レースシミュレーションの滑らかな進行 & ダッシュボード機能強化

## 概要
レースシミュレーションにおいて発生していた「馬の位置飛び（距離差が急にリセットされる現象）」を根本解消し、ダッシュボードに「データ初期化・再生成」ボタンおよび「ターミナル標準出力（stdout/stderr）のリアルタイムログ表示」を実装しました。

---

## 主な変更点

### 1. レースシミュレーションの位置飛び・ワープの根本解消
- **コース実周長（m）とピクセル周長のスケール整合**:
  - `src/gui/widgets/track_canvas.py`: 各競馬場の芝1周実周長（東京2080m、中山1800m、中京1700m、小倉1600m）とピクセル周長をスケール変換（`scale = peri / lap_dist`）し、走破距離 `pos_m` を正確にトラック周回上のピクセル距離に投影。
  - ゴール地点からレース距離分逆算したスタート位置計算を導入し、周回境界をまたぐ際やゴール前での位置ジャンプを解消。
- **左回りコーナー幾何計算の修正**:
  - 左回りの第3・4コーナー進入時に、y座標が上下反転（`+lane_r` から `-lane_r` へ瞬間移動）していた重大な幾何計算の不連続性を修正。円弧と直線が数学的に滑らかにつながる連続計算へ改修。
- **脚質ペース配分の適正化**:
  - `src/race/engine.py`: 脚質ごとのペース係数を最適化し、道中の最大馬群長を不自然な60馬身（140m）から、現実の競馬に即した10〜18馬身（約25〜44m）へと自然に凝縮。直線での不自然な急加速・集団化の錯覚を解消。

### 2. ダッシュボードへの「データ初期化・再生成」ボタン追加
- `src/gui/views/dashboard_view.py`:
  - ヘッダー右側に目立つ専用ボタンスタイルで `[🔄 データ初期化・再生成]` を配備。
  - 誤操作を防ぐ確認ダイアログ（`QMessageBox.question`）を表示。
  - バックグラウンドワーカー（`DataResetWorker`）によりUIをフリーズさせずに、データベーススキーマの再構築および初期データ（種牡馬60頭、繁殖牝馬600頭、現役馬1250頭、騎手90名、調教師60厩舎など）を一括再生成。
  - 完了後にダッシュボードの集計カードおよび他タブ（競走馬一覧、レース結果等）を即座に最新状態へ自動更新。

### 3. ダッシュボード実行ログへのターミナル出力（stdout/stderr）表示連動
- `src/gui/views/dashboard_view.py`:
  - `OutputRedirector` クラスを実装し、`sys.stdout` および `sys.stderr` をフック。
  - 年進行処理、週進行、初期データ生成処理等の詳細なログ（ターミナルに出ていた進捗メッセージ）が、ダッシュボードの「シミュレーション実行ログ」欄にリアルタイムで流れるよう統合。
  - メインUIスレッドでのテキスト末尾挿入と自動スクロールに対応。

## 検証結果

1. **位置連続性・馬群長テスト (`verify_continuity.py`)**:
   - 4大競馬場（中京・東京・中山・小倉）すべてにおいて、先頭馬のステップ間ピクセル移動量が滑らかでワープゼロであることを確認。
   - レース道中の馬群長が約17.8馬身（44.4m）で自然に推移することを確認。
2. **ダッシュボード機能テスト (`verify_dashboard.py`)**:
   - ターミナル標準出力がダッシュボードのログウィンドウへ正確にリアルタイム反映されることを確認。
   - 初期化ボタンの配備・連動を確認。
3. **既存ユニットテスト全件合格**:
   - `python3 -m unittest discover -s tests` が `exited with code 0` で全件パス。
