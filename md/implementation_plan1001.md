# レース出走条件の改定および番組表調整 実装計画

## 概要
ユーザーからの要件に基づき、以下の3つの改定を実施します。
1. **レース間隔ルール**:
   - 原則としてレース間隔を最低でも「中4週」（前回出走から5週以上後）空ける。
   - **未勝利馬（`career_wins == 0`）** には上記を適用せず、従来通り「中3週」（前回出走から4週以上後）で出走可能とする。
2. **番組表の調整**:
   - トライアルレースに勝利しても本番G1に出走できない事態を防ぐため、すべてのトライアル競走と対象G1競走の開催週の間隔を最低5週（中4週以上）空けるよう番組表（`annual_program.py`）を調整する。
3. **G1勝利馬の出走制限**:
   - 過去にG1で勝利した馬（`g1_wins > 0`）は、G3競走およびリステッド競走に出走できないものとする。
   - ただし、そのG3/リステッド競走が**トライアルレース（`is_trial = 1`）の場合は出走可能**とする。

### 1. `src/race/entry.py`
- `can_enter_race` メソッド内のレース間隔判定を改定:
  - 未勝利馬（`horse.career_wins == 0`）: `diff_weeks < 4` で出走不可（中3週以上必要）
  - 1勝以上の馬（`horse.career_wins > 0`）: `diff_weeks < 5` で出走不可（中4週以上必要）
- `can_enter_race` メソッド内に G1 勝利馬の出走制限を追加:
  - `horse.g1_wins > 0` かつ `race.grade in (RaceGrade.G3, RaceGrade.L)` の場合:
