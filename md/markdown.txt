# 【指示書】競馬シミュレーションエンジンおよびシステム開発（Python / PyQt6 / SQLite）

あなたは優秀な競馬シミュレーションゲームおよび遺伝アルゴリズムのリードエンジニアです。
以下の詳細要件定義および設計仕様に基づき、Mac（macOS）および Windows の両環境で動作する競馬シミュレーションシステムの設計と実装を段階的（ステップバイステップ）に進めてください。

---

## 1. プロジェクト概要 & アーキテクチャ原則
- **目的**: 遺伝アルゴリズム（ポリジーン・ミオスタチン・母系遺伝）に基づく長期馬群シミュレーションエンジンの構築。
- **動作環境**: **Mac / Windows 両対応**（Python 3.10+ / PyQt6 または PySide6、`pathlib`等によるOS依存なし設計）。
- **データベース構造（Google Drive等との連携）**:
  - 軽量・一括管理が可能な **SQLite** を採用。
  - データベースファイル（`horse_racing_sim.db`）の保存先は設定画面等で自由に変更・指定可能とする（Google DriveやOneDrive等の同期フォルダ内に配置可能）。
- **アーキテクチャ方針**: 
  - データ指向型設計。数値計算・ロジック（CUI/エンジン）と画面描写・UI（GUI/ビューア）を完全分離する。
  - レースシミュレーション結果は 0.1 秒ごとの時系列位置・状態データ（Replay Data）として出力し、ビューアで再生・可視化する。
  - 全競走馬、種牡馬、繁殖牝馬、**生産牧場**、**馬主**の競走成績・血統・履歴・ランキングを SQLite データベースに蓄積し、閲覧・分析可能とする。

## 2. 生産牧場・馬主・馬名自動生成仕様

### 2-1. 生産牧場（Breeder：初期50場 ➔ 動的分化）
- **初期規模**: **50場**（初期状態は各場10〜20頭程度の繋養牝馬でスタート）。
- **動的格差・分化ロジック**:
  - 活躍馬（重賞・G1勝ち馬）を輩出した牧場は、獲得賞金・評判が上昇。
  - 評判上昇に伴い「繋養牝馬枠の拡大」および「質の高い繁殖牝馬の導入」が行われ、シミュレーションを経るにつれて**大手牧場（メガファーム）から小規模牧場へと自然に二極化・階層化**していく。
- **成績管理**: 年間勝ち星、通算勝利数、獲得賞金、G1勝利数、生産者リーディング順位。

### 2-2. 馬主（Owner：初期100人 ➔ 動的分化）
- **初期規模**: **100人**（各馬主に固有の**冠名（Prefix）**を付与。例: 「サトノ」「トウカイ」「シンボリ」等）。
- **動的格差・分化ロジック**:
  - 所有馬の活躍・獲得賞金に応じて購買力（資金）が変動。
  - 獲得賞金の高い馬主は所有頭数を増やし良血馬を優先購買できる一方、低迷馬主は所有頭数が減少し、シミュレーションを経るにつれて**大手馬主から小口馬主へと自然に分化**していく。
- **成績管理**: 年間勝ち星、獲得賞金、所有頭数、G1勝利数、馬主リーディング順位。

### 2-3. 馬名自動生成ロジック
- 幼駒誕生時またはデビュー時に自動命名。
- 命名フォーマット: **`[馬主の冠名] + [単語/血統由来名]`** （例: 「サトノ＋クラウン」「トウカイ＋テイオー」）。
- カタカナ9文字以内（または英語表記）の重複チェックを実施。

## 3. 競走馬能力パラメーター＆遺伝モデル仕様

### 3-1. 能力値とスケール
- 各能力値は `0.0 〜 100.0` の実数（Float）で管理。
  - `50.0`: 全体平均値 ($\mu$)、未勝利〜下級条件レベル
  - `70.0`: G1・重賞勝ち馬レベル
  - `80.0〜`: 歴史的名馬レベル

### 3-2. 遺伝アーキテクチャ（3層構造）
1. **離散遺伝子（ミオスタチン / MSTN）**:
   - `C/C`: 短距離・スプリント型
   - `C/T`: 中距離・万能型
   - `T/T`: 長距離・ステイヤー型
2. **ポリジーン（連続量）**:
   - 「最高速度」「持久力」「瞬発力」「気性」「耐久力」の5能力。
   - 交配計算式: $P_{child} = \mu + \frac{1}{2}h^2(P_{sire}-\mu) + \frac{1}{2}h^2(P_{dam}-\mu) + \epsilon$
   - 基準値 $\mu = 50.0$ （完全固定型。インフレ防止）。
3. **母系遺伝（ミトコンドリアDNA・母性効果）**:
   - 牝系より「心肺機能・底力」の補正値を継承。

### 3-3. 成長・減衰
- **成長型（3パターン）**: 早熟（ピーク 2.5〜3歳） / 普通（ピーク 4〜5歳） / 晩成（ピーク 5〜6歳）
- **加齢衰退**: ピークを過ぎた馬は、毎年全能力が 5%〜10% 減少。
- **故障ルール**: 故障（怪我）の概念はなし。

## 4. 個体群・繁殖・世代交代ルール

- **規模**: 年間誕生 500 頭（牡牝 50:50）、現役馬総数 約 1,250 頭。
- **繁殖群規模**: 種牡馬 50〜100 頭 / 繁殖牝馬 500〜1,000 頭。
- **種付け上限**: 1頭の種牡馬あたり年間最大 30 頭まで。
- **サイアーライン保護**: 断絶寸前の父系ラインから最低1頭の後継種牡馬を強制昇格。
- **引退・昇格判定**:
  - **3歳未勝利足切り**: 3歳9月（第28週）時点で0勝の馬は自動全数引退。
  - **早期繁殖昇格**: G1勝ち馬・主要重賞勝ち馬は 4〜5 歳で早期引退し繁殖入り。
  - **衰退・高齢引退**: 能力減衰により下級条件で着外が続く馬、または 8 歳到達馬は引退。繁殖牝馬は 18〜20 歳で引退。

## 5. レース体系・競馬場・番組表仕様

### 5-1. 競馬場モデル（4場構成・全レース良馬場固定）
- **競馬場A（阪神/京都型）**: 右回り・大箱 / 直線 400m / 平坦
- **競馬場B（東京型）**: 左回り・大箱 / 直線 520m / 坂あり
- **競馬場C（中山型）**: 右回り・小箱 / 直線 310m / 急坂あり
- **競馬場D（ローカル型）**: 右回り・小箱 / 直線 300m / 平坦
- **馬場状態**: 全レース **「良馬場」固定**。

### 5-2. 2歳戦の性別分離
- 2歳戦は新馬・未勝利・重賞にいたるまで **牡馬（混合含む）と牝馬限定を明確に分離**。
- **2歳王者決定戦（G1）**:
  - `2歳牝馬王者決定戦`（芝1600m・A場）
  - `2歳牡馬マイル王者決定戦`（芝1600m・A場）
  - `2歳牡馬中距離王者決定戦`（芝2000m・C場）
  - `2歳ダート王者決定戦`（ダ1400m・C場）

### 5-3. G1出走枠の選定ルール（直行対応・優先出走権）
- **G1フルゲート上限**: 各レース 16〜18 頭。
- **出走権の決定ロジック**:
  1. **優先出走権**: 指定のトライアルレース上位馬（1〜3着）に無条件の出走権を付与。
  2. **収得賞金枠**: 優先出走権を持たない馬（トライアル非経由・直行馬を含む）は、**累積収得賞金が高い順に出走枠を自動割り当て**。

## 6. レースシミュレーション＆タイム計算エンジン

### 6-1. 脚質（4区分）
- 「逃げ」「先行」「差し」「追込」のペース配分および直線スパート補正。

### 6-2. 走破タイム確定アルゴリズム
- 走破タイム calculation:
  $\text{Time} = \text{基準タイム} - \left( \alpha \times \text{最高速度} + \beta \times \text{瞬発力} \right) + \text{距離ペナルティ} + \text{乱数}$
- **良馬場・初期基準タイム**:
  - 1000m: `01:10.0` (70.0秒)
  - 1200m: `01:25.0` (85.0秒)
  - 1400m: `01:41.0` (101.0秒)
  - 1600m: `01:57.0` (117.0秒)
  - 1800m: `02:13.0` (133.0秒)
  - 2000m: `02:30.0` (150.0秒)
  - 2400m: `03:05.0` (185.0秒)
  - 3000m: `04:00.0` (240.0秒)
  - 3600m: `04:59.0` (299.0秒)
  *(※1000m=14.0秒/200m平均とし、200m増加ごとに200mラップが0.2秒ずつ加算される計算)*
