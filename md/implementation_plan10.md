# 馬名命名仕様の改修計画（[冠名]+[単語] への純化および重賞馬名重複防止ルール）

## 概要
生まれた馬の名前が `[冠名] + [単語] + [単語]`（2単語合成）になっている現象を修正し、ユーザー様のご指定通り **`[冠名] + [単語]`** のみで生成されるように変更します。
あわせて、馬名の重複回避ルールとして **「重賞(G1, G2, G3)を勝利した馬の名前はつけない（永久欠番）」** を厳格に適用し、現役・種牡馬・繁殖牝馬との同時代重複を防ぎつつ、重賞未勝利の引退馬の名前は再利用できる仕組みを整備します。

---

## 背景と問題の根本原因
- 以前の実装では、馬名単語の重複を避けるために「現在活動中の馬が使っている単語（`used_active_words`）」を全馬主横断で排他管理していました。
- しかし単語総数（約1,060語）に対して頭数（初期生成約2,110頭＋毎年の生産約500頭）が多いため、単語が枯渇し、フォールバック処理である「2単語合成（`_generate_compound_word`）」が発動して `[冠名] + [単語] + [単語]`（例: `クラマクリソコラステラ`、`サカキタイガーズアイコンスタンティヌス` など）となっていました。
- 100人の馬主（100通りのユニーク冠名）× 約1,060語 ＝ 約10万通りの組み合わせが存在するため、冠名と単語の1対1結合 `[冠名] + [単語]` だけで十分な命名空間が存在します。

---

## 新命名ルールと重複排除の仕様

1. **命名フォーマット**:
   - 必ず **`[冠名] + [単語]`** （1単語のみ）。
   - 馬名は9文字を超えても許容（冠名と単語を素直に結合した自然な命名）。
2. **名前の重複回避ルール**:
   - **重賞(G1, G2, G3)勝利馬の名前**: 過去の引退馬を含め、一度でも重賞を勝った馬の名前は永久に命名不可（永久保護）。
   - **現在活動中の馬の名前**: 現役馬（`is_active=1`）、供用中種牡馬（`is_sire=1`）、供用中繁殖牝馬（`is_dam=1`）と同じ名前は命名不可（同時代重複不可）。
   - **同一世代内の重複**: 当該年度に生まれた当歳馬同士で同じ名前にならないよう即時登録。
   - **名前の再利用**: 重賞未勝利（G1/G2/G3すべて0勝）で引退・非活動となった馬の名前は再利用可能。
3. **DBスキーマ整合性**:
   - `horses` テーブルの `name TEXT NOT NULL UNIQUE` の `UNIQUE` 制約を解除（`name TEXT NOT NULL`）。これにより重賞未勝利の引退馬と同名馬が将来誕生してもエラーになりません。

---

## 変更対象ファイルと改修内容

### 1. `src/generators/name_generator.py`
- `_generate_compound_word`（2単語合成）を廃止。
- `generate_name` メソッドを改修:
  - 候補単語プールから `len(prefix + word) <= 9` かつ `(prefix + word) not in self.used_names` の単語を選定して `f"{prefix}{word}"` を返す。
  - 牡馬/牝馬の性別・カテゴリに応じた自然な単語優先度は維持。
  - `set_forbidden_names(names: Set[str])` メソッドを追加し、禁止名セット（重賞勝ち馬＋現役馬）を外部から一括設定可能にする。

### 2. `src/core/breeding.py`
- `_sync_existing_names(self, conn) -> None` を改修:
  - 重賞(G1, G2, G3)勝利馬（`g1_wins > 0 OR g2_wins > 0 OR g3_wins > 0`）の名前を抽出。
  - 現在活動中の馬（`is_active = 1 OR is_sire = 1 OR is_dam = 1`）の名前を抽出。
  - これらの和集合を禁止名前セットとして `self.name_gen.set_forbidden_names(...)` に登録。

### 3. `src/db/schema.py`
- `horses` テーブルの `name TEXT NOT NULL UNIQUE` を `name TEXT NOT NULL` に変更（インデックス `idx_horses_name` を追加）。

### 4. `tests/test_horse_name_uniqueness.py`
- 新仕様に対応したユニットテストの改修・拡充:
  - すべての生成馬名が `[冠名] + [単語]` であり、かつ9文字以内であることのテスト。
  - 重賞勝ち馬の名前が絶対に再利用されないことのテスト。
  - 重賞未勝利で引退した馬の名前が再利用可能であることのテスト。

---

## 検証手順

1. **ユニットテストの実行**:
   - `python3 -m unittest discover tests` を実行し、全テストがパスすることを確認。
2. **交配・出産シミュレーションの実機検証**:
   - 複数年の交配・出産処理（`BreedingEngine.process_annual_breeding`）を実行し、誕生する当歳馬（毎年500頭）の名前がすべて `[冠名] + [単語]`（9文字以内）であることを確認。
   - 重賞勝ち馬と同じ名前が付けられていないことをSQLで検証。
