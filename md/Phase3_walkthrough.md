# 【Phase 3】番組表登録・レースシミュレーション＆走破タイム計算エンジン・年間カレンダー統合 完了報告

仕様書（`md/markdown.txt`）のセクション5・6に基づき、**4大競馬場モデル、年間48週の全レース体系（クラシック三冠・前哨戦・古馬王道G1・2歳王者決定戦・条件戦）、優先出走権・フルゲート選定、走破タイム確定アルゴリズム、0.1秒単位の時系列リプレイ生成、週/月/年進行コントローラ、および5大リーディングランキング集計機能**の実装・検証がすべて完了しました。

## 1. 実装モジュールと主な設計内容

### ① コース特性モデル (`src/race/track.py`)
- 仕様書準拠の4大競馬場モデルを定義：
  - **Track A (阪神/京都型)**: 右回り・大箱 / 直線 400m / 平坦。スピードと持続力の王道コース。
  - **Track B (東京型)**: 左回り・大箱 / 直線 520m / 坂あり。長い直線とだらだら坂。瞬発力とスタミナ重視。
  - **Track C (中山型)**: 右回り・小箱 / 直線 310m / 急坂あり。ゴール前急坂と耐久力（Durability）重視。
  - **Track D (ローカル型)**: 右回り・小箱 / 直線 300m / 平坦。先行力と器用さ重視。

### ② 年間48週レース番組表ビルダー (`src/race/program.py`)
- 1年を**48週（12ヶ月 × 4週）**とし、年間599レースを編成・DB登録：
  - **3歳牡馬クラシック**: 皐月賞(C2000), 日本ダービー(B2400), 菊花賞(A3000) ＋ トライアル7競走（弥生賞, スプリングS, 若葉S, 青葉賞, プリンシパルS, セントライト記念, 神戸新聞杯）
  - **3歳牝馬クラシック**: 桜花賞(A1600), オークス(B2400), 秋華賞(A2000) ＋ トライアル7競走（チューリップ賞, フィリーズR, アネモネS, フローラS, スイートピーS, ローズS, 紫苑S）
  - **古馬王道G1 ＆ トライアル**: 天皇賞(春), 宝塚記念, 天皇賞(秋), ジャパンC, 有馬記念, 安田記念, マイルCS, 高松宮記念, スプリンターズS, フェブラリーS, チャンピオンズC, 大阪杯, エリザベス女王杯
  - **2歳王者決定戦**: 2歳牝馬王者(A1600), 2歳牡馬マイル王者(A1600), 2歳牡馬中距離王者(C2000), 2歳ダート王者(Cダ1400)
  - **性別分離 ＆ 条件戦**: 2歳戦は第21週から開幕し牡馬/牝馬を分離。1勝〜3勝クラス、OP特別、新馬戦、未勝利戦を芝・ダート全距離でバランス配置。

### ③ 出走登録・優先出走権・フルゲート選定・騎手配当 (`src/race/entry.py`)
- **優先出走権判定**: トライアル競走1〜3着馬（重賞）および1着馬（リステッド/OP）に対象G1の優先出走枠を自動付与。
- **フルゲート選定**: 優先権保持馬 ＋ 残り枠を「累積収得賞金順」で足切り（最大18頭）。
- **騎手起用ロジック**:
  - 基本は**厩舎所属騎手を優先起用**。
  - 重賞（G1, G2, G3）や有力馬（上位人気・実力馬）の場合は、**実績上位のフリー騎手を優先選定**。
  - 同一レース内の騎手バッティングを自動解決。

### ④ レースシミュレーション＆走破タイム確定エンジン (`src/race/engine.py`)
- **基準タイムテーブル**: 1000m（70.0秒）〜3600m（299.0秒）の距離別良馬場基準タイムを補間。
- **走破タイム確定アルゴリズム**:
  $$\text{Time} = \text{BaseTime} - (0.16 \times \text{Speed} + 0.10 \times \text{Accel}) \times \text{Scale} + \text{DistPenalty} + \text{TrackPenalty} - \text{JockeyBonus} - \text{TrainerBonus} - \text{VitalityBonus} + \epsilon$$
  - ミオスタチン（MSTN）適性距離との乖離ペナルティ（スタミナ値でカバー可能）。
  - 耐久力（Durability）不足時の坂失速ペナルティおよび大箱/小箱と脚質の相性補正。
  - 騎手の技量・直線追い（drive）・経験値、および調教師のスキルレベルによるタイム短縮。
  - 着差判定（ハナ、アタマ、クビ、1/2、1 1/4、2馬身、3馬身、大差など）。
- **0.1秒単位（0.5秒サンプリング）時系列リプレイ生成**:
  - 脚質4区分（逃げ・先行・差し・追込）のペース配分・位置取りをシミュレーションし、JSONデータとして保存。

### ⑤ 年間カレンダー進行コントローラ (`src/race/calendar.py`)
- **週進行（`run_week`）**: 指定週の全レースを実行し、結果をDBに保存。馬・騎手・厩舎・馬主・生産牧場の戦績・賞金・重賞勝ち鞍を一括自動更新。
- **月進行（`run_month`）** / **年進行（`run_year`）**: 複数週または年間48週を一括実行。
- **未勝利戦足切り（第28週）**: 3歳未勝利馬（0勝馬）の引退判定および牝馬の繁殖登録を自動実行。

### ⑥ 5大リーディング集計モジュール (`src/race/rankings.py`)
1. **騎手リーディング**: 勝利数、出走数、勝率、G1/G2/G3重賞勝利数、獲得賞金、所属/フリー区分
2. **調教師リーディング**: 勝利数、出走数、勝率、重賞勝利数、調教師スキルレベル、獲得賞金
3. **馬主リーディング**: 獲得賞金順、所有馬勝利数、G1勝利数、資金残高
4. **生産牧場リーディング**: 生産馬獲得賞金順、勝利数、G1勝利数、資金残高
5. **サイアー（種牡馬）リーディング**: 産駒獲得賞金順、産駒勝利数、産駒G1数、**AEI（アーニングインデックス）**

## 3. 追加されたCLIオプションと対話メニュー

### CLIオプション
- `python3 main.py --register-program 1`: 1年度の年間番組表（599レース）を生成・登録
- `python3 main.py --program [WEEK]`: 番組表・スケジュール確認
- `python3 main.py --simulate-week [WEEK]`: 指定週（1〜48週）のレースを開催実行
- `python3 main.py --simulate-month [MONTH]`: 指定月（1〜12月・4週分）のレースを一括実行
- `python3 main.py --simulate-race-year [YEAR]`: 年間48週の全レースを一括シミュレーション
- `python3 main.py --race-results [RACE_ID]`: レース結果・タイム・着差・獲得賞金を表示
- `python3 main.py --rankings [jockey|trainer|owner|breeder|sire]`: 各種リーディングを表示

### 対話型コンソールメニュー（`python3 main.py`）
メニュー項目を拡充し、対話形式でレース開催・番組表閲覧・リーディング確認・レース結果閲覧が可能です。
