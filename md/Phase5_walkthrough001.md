## 2. 数理シミュレーション検証：毎年600頭で完結するレース規模

### 前提条件
- **誕生頭数**: 毎年600頭（牡馬300頭、牝馬300頭 同数誕生）
- **1R頭数**: **8頭限定**（フルゲート8頭固定）
- **出走間隔**: **最低中2週**（前走から3週以上経過が必要）
- **引退条件**: 
  - 3歳9月末（第36週）未勝利馬強制引退
  - 最大8歳末完全引退
  - 4歳〜8歳の成績不振（大敗続き・1勝C停滞）およびピークアウト引退モデル

### 数理計算結果
- **定常現役頭数**: 約 **1,255頭**
- **1頭あたりの年間平均出走回数**: 約 **6.5〜7.0走**
- **年間総延べ出走枠需要**: $1,255 \times 6.8 \approx 8,534$ 走枠
- **必要レース数**: $8,534 \div 8 = 1,066$ レース（**週あたり約22〜23レース**）

### 開催割当（全48週）
- **通常開催週（3場開催）**: 各場 7〜8 レース × 3場 ＝ **22〜24レース / 週**
- **夏期ローカル週（2場開催）**: 各場 11〜12 レース × 2場 ＝ **22〜24レース / 週**
- **年間総レース数**: **1,073 レース**（全レース8頭限定）

実シミュレーションテスト（第1週〜第8週）において、1Rあたりの平均出走頭数が **7.4〜8.0頭** で安定推移し、頭数不足や出走詰まりを起こすことなく完全に完結することを実証しました。

## 4. 出走資格ルールと制御実装

| 条件区分 | 実装内容 |
| :--- | :--- |
| **出走間隔** | **最短中2週**（`diff_weeks >= 3`）。連闘・中1週での出走は完全不可。 |
| **2歳馬** | 未勝利馬は重賞出走不可（**1勝以上の勝ち馬のみ出走可能**）。 |
| **3歳馬（春期: 1〜22週）** | 未勝利・1勝馬は重賞出走不可（**1勝クラス勝利＝通算2勝以上が出走条件**）。 |
| **3歳馬（夏秋: 23週以降）**| 重賞出走には**重賞2着以内実績** または **3勝クラス勝利（OP入り）** が必要。 |
| **4歳以上** | 重賞出走には **通算3勝以上** が必要。 |
| **未勝利足切り** | **3歳第36週（9月末）終了時** に未勝利の馬は一括強制引退処理を実施。 |
| **引退モデル** | **8歳末での完全引退**。4歳以降は「通算5走以上で入着なし」「高齢かつピークアウト」による自然引退確率モデルを適用。 |
