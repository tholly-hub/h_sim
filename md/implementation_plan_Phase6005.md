# オッズ算出・レース体系・リーディング・グラフ改修の実装計画

ユーザーのご要望に基づき、以下の機能改修およびシステム最適化を行う計画を策定しました。

---

## 📌 ユーザー要望の整理と改修方針

### 1. オッズの付け方の見直し
- **現状の課題**: 単勝1倍台の馬がかなりの確率で勝てない状況があり、成績が伴っていない馬でも内部能力値の差だけで1倍台になっている。
- **改善方針**:
  - 実績（前走着順、直近3走成績、通算勝率・連対率、重賞勝ち鞍、収得賞金）をオッズ評価の最重要指標として反映。
  - 新馬戦・未勝利戦などキャリアの浅いレースでは市場人気が割れやすくし、根拠のない1倍台を防止。
  - 単勝1倍台（1.1〜1.9倍）になる基準を「圧倒的な実績（重賞勝ち・高勝率・連対率など）＋高い適性」に厳格化。
  - 1倍台になった馬は適正に高勝率（50%以上）となるようオッズと勝敗の整合性を向上。

### 2. レース体系・エントリー条件の見直し
- **古馬（4歳以上）重賞の開催制限**:
  - 古馬が出現するまでは、2歳・3歳限定のリステッド・重賞のみ開催（1年目・2年目は4歳以上/3歳以上の古馬重賞・古馬Lを開催除外/スキップ）。
- **3勝クラスの開催時期制限**:
  - 3勝クラスは10月1週（第37週）以降に開催（1月〜9月（第1〜36週）は3勝クラスを開催しない）。
- **3歳馬のエントリー条件改定**:
  - 5月第4週（第20週）まで: **1勝馬以上** がリステッド競走・重賞にエントリー可能。
  - 6月第1週（第21週）以降: **2勝馬以上** がリステッド競走・重賞にエントリー可能。
- **4頭未満レースの中止ルール**:
  - 出走頭数が4頭に満たない（1〜3頭）レースは「中止」とし、レースシミュレーションおよび結果保存を行わない。
  - 同時に、可能な限り4頭以上のフルゲート頭数が揃うようエントリー割り当てを最適化。

### 3. データベース & クラス定義
- **重賞レースDB**:
  - 過去の重賞レース一覧から、レース結果ダイアログ（`RaceResultDialog`）やリプレイ動画（`RaceReplayView`）をスムーズに閲覧できるように連携を強化。
- **年度代表馬**:
  - 「当該年度を手動実行」ボタンをUIから廃止（12月4週終了時に自動選出される仕組みを維持）。
- **競走馬クラスの定義**:
  - **重賞レース（G1/G2/G3）を勝利した馬は、通算勝利数（1勝・2勝含む）に関わらずオープン馬（OP）と定義**。
  - クラス判定関数および表示（名鑑・出馬表・馬詳細）を統一。

### 4. サイヤーリーディング & リーディング順位推移グラフ
- **サイヤーリーディング**:
  - 全馬集計の「総合」のほか、「2歳馬」「3歳馬」に限定した集計・表示切り替え（タブ/コンボボックス）を追加。
- **リーディング順位推移グラフ（新機能）**:
  - 各リーディング（騎手・調教師・馬主・生産牧場・種牡馬）の行または名前をクリックすると、各年度のリーディング順位（1位〜）の推移をプロットした折れ線グラフ（モーダルダイアログ）を表示。

### 5. 走破タイムグラフ・アナリティクス改修
- **縦軸の表示形式**: 秒表示ではなく **「分:秒」表示**（例: `1:33.4`）に変更。
- **横軸**: 年（Year）。
- **年次最速タイムグラフの削除**: 「年次最速タイム」折れ線を削除。
- **レコードタイム推移**: レコード更新の推移グラフ（各年度時点での歴代レコードタイム）を表示。
- **平均勝ちタイム**: 各年12月4週（年末時点）の年間集計値として表示。

## 🧪 検証計画

1. **オッズ算出の検証**:
   - キャリア・実績の異なる馬でオッズ分布をテストし、実績馬に適切な人気がつき、単勝1倍台馬の勝率が50%以上となることを検証。
2. **レース体系・エントリーの検証**:
   - 1年目・2年目に古馬重賞が生成・開催されないこと、3勝クラスが10月1週以降のみ開催されることを検証。
   - 3歳馬の5月4週（1勝以上）および6月1週以降（2勝以上）の重賞エントリー資格を検証。
   - 4頭未満のレースが安全に中止扱いとなることを検証。
3. **クラス定義・UI表示の検証**:
   - 重賞勝ち馬（1勝馬・2勝馬含む）がオープン馬として判定・表示されることを検証。
   - 重賞DBでの結果・動画表示、年度代表馬手動ボタン削除の確認。
4. **リーディング・グラフの検証**:
   - 総合・2歳・3歳のサイアーリーディング集計の動作確認。
   - 騎手・調教師・馬主・牧場・種牡馬の順位推移グラフダイアログの描画確認。
   - 走破タイムグラフの縦軸（分:秒表示）、レコード推移、12月4週平均勝ちタイムの描画確認。
5. **全テストスイートの実行**: `python3 -m unittest discover -s tests` で全件パスを確認。
