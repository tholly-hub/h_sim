# 初年度現役馬構成および開催・番組表の改善 完了報告

ユーザー様からのご要望に基づき、**「初年度は2歳馬のみ存在すること」** をはじめとする以下の仕様変更と調整を完了し、全76件のテストに合格しました。

---

## 1. 実施内容の概要

### ① 初年度現役競走馬を「2歳馬のみ」に設定
- **初期生成馬の世代構成**:
  - 初年度（1年目）開始時、現役馬は **2歳馬350頭のみ**（全頭未出走・0戦0勝）を生成します。
  - 3歳以上の古馬は生成されません。
  - 翌年（2年目）のデビュー用として **1歳幼駒350頭** も初期生成され、年末の年進行処理で自動的に2歳現役馬として厩舎に入厩します。
  - これにより、1年目は2歳新馬戦（6月1週〜）・未勝利戦・2歳重賞（阪神JF、朝日杯FS、ホープフルS等）からゲームが自然にスタートし、2年目には3歳クラシック路線＋新2歳馬、3年目には古馬＋3歳＋2歳と順次世代が積み上がります。

### ② ダッシュボードの「競馬場別タブ」表示
- 2行目のレース選択を `QTabWidget` による **競馬場別タブ（例: 📍 東京競馬場 (8R) / 📍 京都競馬場 (8R)）** に刷新。
- レース順はグレード昇順（未勝利 → 新馬 → 1勝 → 2勝 → 3勝 → リステッド/OP → G3 → G2 → G1）で整列。
- 出走馬が存在する開催レースのみを過不足なく表示。

### ③ 番組表の2〜3場開催完全整合
- 全48週で競馬場の開催スケジュール（2〜3場開催）と重賞・リステッド・条件戦の配置が完全に整合。
- 安土城ステークス（21週・阪神）など、開催競馬場以外のレースが単独発生する不整合を排除。
