# 実装完了サマリー (Walkthrough)

## 1. 実施した改修内容

### ① リーディング画面での戦績・重賞の表示方法変更
- 5大リーディング（騎手・調教師・馬主・生産牧場・種牡馬）における戦績および重賞勝利数の表示を、従来の括弧付き形式からハイフン区切り形式に変更しました。
  - **戦績**: `10-5-3-20`（1着-2着-3着-着外）
  - **重賞**: `1-0-2`（G1-G2-G3）

### ② 産駒の厩舎への入厩方法（初年度ランダム & 2年目以降ドラフト優先入厩）
- **初年度**: 初期生成時、特定種牡馬の産駒が同じ厩舎に集中しないよう、父母をランダムかつ均等に配分。全厩舎に多様な種牡馬の産駒が所属するように改善しました。
- **2年目以降**: 
  - **情報の不完全性**: 厩舎は馬の真の潜在能力（個体値）を直接知ることはできず、種牡馬・繁殖牝馬の能力値、種付料、評判（観測ノイズ）から算出した「血統期待値（評判スコア）」に基づいて馬を評価します。
  - **実績優先ドラフト**: 前年勝率・重賞勝数・スキルレベルが高い厩舎から優先的に評判の高い2歳新馬を指名・入厩させます。

### ③ 馬の能力・成長曲線と調教師育成ボーナス
- **成長曲線（`growth_type`）**:
  - `EARLY`（早熟）: 2歳 0.78 / 3歳 1.00（ピーク） / 4歳 0.95 / 5歳 0.85 / 6歳 0.70
  - `NORMAL`（普通）: 2歳 0.65 / 3歳 0.88 / 4〜5歳 1.00（ピーク） / 6歳 0.88 / 7歳 0.72
  - `LATE`（晩成）: 2歳 0.55 / 3歳 0.75 / 4歳 0.90 / 5〜6歳 1.00（ピーク） / 7歳 0.88
- **調教師育成ボーナス**:
  - 所属調教師のスキルレベル（`skill_level`）に応じて、成長度・発揮率（`current_ability_rate`）に最大約+3%の育成ボーナスが付与されます。
  - 騎手のスキルはレース中の能力引き出し率にのみ作用し、馬の基礎能力や成長度には影響を与えない仕様を維持しています。
