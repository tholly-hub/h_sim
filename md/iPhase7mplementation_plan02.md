# 3年目2歳戦不成立修正、種付け・出産サイクル実装、電光掲示板レース番号修正の実装計画

## 概要
1. **3年目に2歳戦の番組が出なくなる不具合の修正 & 幼駒誕生・種付けサイクルの完全実装**:
   - 初期状態（1年目開始時）に「現役2歳馬(600頭)」「1歳馬(600頭)」「0歳馬/当歳馬(600頭)」を初期生成。
   - 毎年 **3月**（第9週〜第12週）: 仔馬誕生（前年種付けされた受胎馬から0歳当歳馬600頭が誕生）。
   - 毎年 **4月**（第13週〜第16週）: 種付け交配イベント（1月に新種牡馬・新繁殖牝馬になった馬を含む全供用中馬の交配）。
   - 1月1週年進行時（`advance_year`）: 全馬加齢（0歳→1歳、1歳→2歳）。2歳になった馬が厩舎ドラフト入厩し、6月（第21週）に新馬戦デビュー。
   - これにより、引退した新種牡馬・繁殖牝馬の子供が3年後にデビューする自然な世代交代サイクルが成立し、3年目以降も2歳戦が継続します。
2. **電光掲示板のレース番号（R番号）の完全正確化**:
   - フィルター適用時（G1のみ等）でも、各競馬場・当該週の全確定レース一覧における正規のレース番号（1R〜12R）を正確に算出して表示。
   - 電光掲示板（TrackCanvas / RaceBoardWidget）およびリプレイ画面、各種ダイアログの表示を統一。
3. **秋華賞・菊花賞トライアルの確認**:
   - 阪神・中山のトライアル競走（ローズS、紫苑S、神戸新聞杯、セントライト記念）の定義・設定の整合性を確認・維持。

## Proposed Changes

### 1. 初期データ生成 (`src/generators/initializer.py`)
- 初期生成時に、2歳馬600頭（`age = 2`, `birth_year = -1`）、1歳馬600頭（`age = 1`, `birth_year = 0`）に加え、**0歳馬600頭（`age = 0`, `birth_year = 1`, `is_active = 0`, 牡300頭・牝300頭）** を生成する処理を追加。

### 2. 繁殖・交配および年・月サイクル (`src/core/breeding.py`, `src/core/lifecycle.py`, `src/race/calendar.py`, `src/gui/views/dashboard_view.py`)
- `BreedingEngine`:
  - 毎年4月に種付け交配処理を行い受胎（または交配記録）、毎年3月に当歳馬誕生処理（0歳馬登録）を行うメソッド群を整備。
- `CalendarController` / `DashboardView`:
  - 毎年3月進行時（第9週）に「当歳馬誕生イベント（0歳馬登録・ダイアログ表示）」を実行。
  - 毎年4月進行時（第13週）に「年間種付けイベント（種牡馬×繁殖牝馬交配・ダイアログ表示）」を実行。
  - 毎年1月1週進行時（`advance_year`）に「全馬加齢・2歳馬入厩・8歳馬引退・表彰・新種牡馬/新繁殖牝馬登録」を実行。

### 3. 電光掲示板のレース番号修正 (`src/gui/views/race_replay_view.py`, `src/gui/widgets/track_canvas.py`, `src/gui/widgets/race_board_widget.py`)
- `race_replay_view.py`:
  - `load_race_list` において、グレードフィルター適用時でも、該当競馬場・当該週の全開催レース（`results` に存在するレース）の中から正確なR番号（1R〜12R）を計算してコンボボックスに表示。
  - `_load_race_data` において、電光掲示板に渡す `race_num` を、ダッシュボードと同じ基準（全確定レースの `GRADE_SORT_ORDER` 昇順、`distance` 昇順、`race_id` 昇順のインデックス + 1）で正確に算出して渡す。
