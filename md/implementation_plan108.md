# ダッシュボードのレース並び順改修および競走馬戦績の日付表記修正 計画書

## 概要
1. **ダッシュボードのレース一覧のソート順変更**:
   - 競馬場ごとにグループ化・整列。
   - 同一競馬場内のレースを、グレードの低い順（未勝利馬 ➔ 新馬 ➔ 1勝クラス ➔ 2勝クラス ➔ 3勝クラス ➔ リステッド/オープン ➔ G3 ➔ G2 ➔ G1）に整列。
2. **各馬のレース戦績（出走履歴）における年月週の表記修正**:
   - 競走馬詳細ダイアログの出走全レース履歴テーブルにおいて、`年/月/週` に含まれるスラッシュ（`/`）を削除し、`〇〇年〇月〇週` 表記に変更。

---

## 変更内容

### 1. ダッシュボード画面 (`src/gui/views/dashboard_view.py`)
- レース一覧のソートロジックを追加。
  - **競馬場順序 (`TRACK_ORDER`)**: 東京、中山、京都、阪神、中京、新潟、福島、小倉、地方競馬場等の体系順。
  - **グレード順序 (`GRADE_ORDER`)**:
    1. `MAIDEN`（未勝利）
    2. `NEWCOMER`（新馬）
    3. `COND_1W`（1勝クラス）
    4. `COND_2W`（2勝クラス）
    5. `COND_3W`（3勝クラス）
    6. `L` / `OP`（リステッド / オープン）
    7. `G3`（G3）
    8. `G2`（G2）
    9. `G1`（G1）
- `_load_week_data` 内で取得したレースリストを上記キーでソートしてテーブルに描画。

### 2. 競走馬詳細ダイアログ (`src/gui/views/horse_detail_dialog.py`)
- 出走全レース履歴の「年・週」列のフォーマットを修正。
  - 修正前: `f"{r['year']:04d}年/{m_num:02d}月/{w_in_m}週"` （例: `0001年/06月/1週`）
  - 修正後: `f"{r['year']}年{m_num}月{w_in_m}週"` （例: `1年6月1週`）

---

## 検証計画
- ユニットテストを作成し、以下の動作を確認:
  1. ダッシュボードのレース一覧が、競馬場ごと かつ 未勝利 ➔ 新馬 ➔ 1勝 ➔ 2勝 ➔ 3勝 ➔ L/OP ➔ G3 ➔ G2 ➔ G1 の順にソートされていること。
  2. 競走馬詳細ダイアログの履歴テーブルの日付カラムに `/` が含まれず `〇年〇月〇週` の形式で正しく表示されること。
