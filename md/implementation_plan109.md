# リーディング表示項目拡充 & オッズ計算適正化 実装計画書

## 概要
ユーザー様からのご要望に基づき、以下の機能改修を実施します：
1. **騎手・調教師リーディング**: 「年齢」列を追加。
2. **生産牧場リーディング**: 「種牡馬頭数」「繁殖牝馬頭数」列を追加。
3. **サイヤーリーディング**: 「現役産駒数」列を追加。
4. **オッズ計算の適正化**:
   - 2歳戦や重賞等で有力な馬（実力上位馬）に700倍〜999.9倍などの異常なオッズがつく不具合を解消。
   - 馬場・距離適性ペナルティの過剰適用を見直し、Softmax温度/支持率確率モデルをJRA準拠の自然なレンジ（実力上位1〜3倍、中穴10〜40倍、大穴でも50〜200倍程度）に適正化。

---

## 変更内容

### 1. オッズ計算エンジンの改善 (`src/race/engine.py`)
- **不具合原因**:
  - `calculate_odds` において、馬場適性不一致（`-25.0`）や距離適性外れ（`-20.0`）のペナルティが過大であり、さらに Softmax の温度パラメータ `temp = 4.2` が極度に急峻だったため、スコア差が 20〜30 あるだけで勝率確率が $0.0001$ 以下に潰れ、オッズが 700〜999.9倍（カンスト）に跳ね上がっていた。
  - 2歳戦での `current_ability_rate` の差（早熟0.78 vs 普通0.65 vs 晩成0.55）もオッズに過剰に作用していた。
- **改善ロジック**:
  - 基礎能力・素質・実績・調子・騎手能力をバランスよく統合。
  - 馬場・距離ペナルティを現実的な範囲（最大 `-4.0` 〜 `-6.0` 程度）に緩和。
  - 確率変換に適切な温度パラメータ（`temp = 12.0`）および最低支持率フロア（各馬最低 0.5%〜1.0%）を適用し、実社会の単勝オッズ市場に即した滑らかな分布に修正。

### 2. リーディング集計モジュールの拡張 (`src/race/rankings.py`)
- **騎手 (`get_jockey_rankings`)**:
  - SQLクエリに `j.age` を追加。
- **調教師 (`get_trainer_rankings`)**:
  - SQLクエリに `t.age` を追加。
- **生産牧場 (`get_breeder_rankings`)**:
  - 各牧場が繋養している「種牡馬数 (`sire_count`)」「繁殖牝馬数 (`dam_count`)」を集計・追加。
- **サイアー (`get_sire_rankings`)**:
  - 該当種牡馬の「現役産駒数 (`active_progeny_count`)」を集計・追加。

### 3. リーディング画面UIの拡張 (`src/gui/views/rankings_view.py`)
- テーブルカラム構成を新仕様に更新：
  - **騎手**: 順位 / 騎手名 / **年齢** / 所属 / 区分 / 戦績 [1-2-3-外] / 勝率 / 重賞 [G1-G2-G3] / 獲得賞金 / 代表乗鞍
  - **調教師**: 順位 / 厩舎名 / **年齢** / 所属 / 得意分野 / 戦績 [1-2-3-外] / 勝率 / 重賞 [G1-G2-G3] / 獲得賞金 / 代表持ち馬
  - **馬主**: 順位 / 馬主名 / 冠名 / 戦績 [1-2-3-外] / 重賞 [G1-G2-G3] / 資金残高 / 獲得賞金 / 代表持ち馬
  - **生産牧場**: 順位 / 牧場名 / 地域 / **種牡馬** / **繁殖牝馬** / 戦績 [1-2-3-外] / 重賞 [G1-G2-G3] / 資金残高 / 生産賞金 / 代表産駒
  - **サイアー**: 順位 / 種牡馬名 (産駒一覧) / サイアーライン / 種付料 / **現役産駒** / 戦績 [1-2-3-外] / 重賞 [G1-G2-G3] / AEI / 獲得賞金 / 代表産駒
