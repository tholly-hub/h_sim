# ウォークスルー: ハロン棒内外配置・視認性向上・走る競走馬2Dグラフィックの再現

ユーザー様からいただいた以下のご要望について、すべて実装および実画面レンダリング・自動検証を完了しました。

1. **ハロン棒の配置位置の変更（走路干渉ゼロ）**:
   - 正面（スタンド前直線）はコースの内側（内ラチ内側・内馬場側）、向正面（バックストレッチ）はコースの外側（外ラチ外側・外周側）に配置し、馬が走る走路（0.0m〜20.0m）に一切干渉しないよう配置。
2. **ハロン棒の数字の視認性向上**:
   - 看板サイズを拡大（直径 35px）し、数字フォントを拡大・太字化（16pt/13pt Black）して遠目でも鮮明に読めるよう改善。
3. **HUDの馬名・オッズ・フォント拡大**:
   - 画面右セクションの上位馬テロップの馬名（11pt Bold）、単勝オッズ（10.5pt Bold）、ゼッケンバッジ（20x20px）を拡大し視認性を向上。
4. **下部のレース状況バー内の数字の拡大**:
   - 馬番丸ゼッケンを直径 26px（半径 13px）に拡大し、数字フォント（11pt/9pt Bold）を拡大。状況バー上のハロン棒看板も直径 19px（9pt Bold）に拡大。
5. **レース場内に走る競走馬のグラフィック再現（2Dギャロップアニメーション）**:
   - 単なる丸いマーカーから、進行方向に向いたサラブレッド馬体（流線型胴体、首、頭部、耳、たてがみ、なびく尾）、モンキー乗り騎手、JRA枠色ゼッケン、馬番を完全ベクター描画。
   - 走破距離とピッチが100%シンクロし、前脚・後脚が前後に力強く伸び縮みする動的ギャロップ（襲歩）運動を完全再現。

## 1. 変更内容一覧

### レース画面・HUD・馬体描画層
- [track_canvas.py](file:///Users/takashihorimatsu/Library/CloudStorage/GoogleDrive-thorimatsu@gmail.com/マイドライブ/h_sim/src/gui/widgets/track_canvas.py):
  - **ハロン棒の内外配置ロジック (`_draw_world_track`)**:
    周回累積距離 `dist_along` から向正面（バックストレッチ）か正面直線かを判定。向正面は `lateral = 23.5m`（外ラチ外側）、正面は `lateral = -3.5m`（内ラチ内側）へ自動配置。走路（0.0m〜20.0m）への干渉を完全排除。看板直径を 35px、フォントを 16pt/13pt Black に拡大。
  - **走る競走馬2Dグラフィック (`_draw_world_horses`)**:
    進行角度 `heading` に基づき各馬ごとにローカル座標系を回転。
    - **胴体・頭首**: 栗毛/鹿毛色の流線型馬体、頭部、耳、たてがみ、なびく尾。
    - **動的ギャロップ四肢**: 前脚2本（肩・膝・球節・黒い蹄）と後脚2本（飛節・球節・黒い蹄）が走破距離 `pos_m` の位相に応じて前後に激しくスイング・伸縮。
    - **騎手**: 白い勝負服、騎手ヘルメット、前傾姿勢のモンキー乗りフォーム。
    - **ゼッケン**: JRA8枠色に応じた枠色ゼッケンと馬番。
  - **下部レース状況バーの拡大 (`_draw_jra_broadcast_hud`)**:
    - 馬番丸ゼッケンを直径 26px（半径 13.0px）に拡大。数字フォントを 11pt/9pt Bold に拡大。
    - 状況バー上のハロン棒標識看板を直径 19px（9pt Bold）に拡大。
  - **上位馬テロップの拡大 (`_draw_jra_broadcast_hud`)**:
    - 馬名を 11pt Bold、単勝オッズを 10.5pt Bold、タイム差を 9.5pt、ゼッケンを 20x20px に拡大。
    - 右セクション幅を 320px に拡張し、中央の状況バー（420px）と重ならない美しい3カラムレイアウトを構築。
