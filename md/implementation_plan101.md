# レース体系再構築および番組表・頭数シミュレーション検討計画

ユーザー様から提示された条件に基づき、JRA 8場（東京・中山・阪神・京都・中京・福島・新潟・小倉）および地方 4場（大井・川崎・船橋・盛岡）の計12場を活用した、全世代（2歳・3歳・4歳以上古馬）の競走馬レース体系・年間番組表の再構築と、頭数・シミュレーション完結性の数理的検証を行います。

---

## 1. 頭数と必要レース数の数理的検討（シミュレーション完結性の検証）

### 1.1 前提条件
- **年間誕生頭数**: 毎年 600 頭（牡馬 300 頭、牝馬 300 頭）
- **未勝利足切り**: 3歳9月末（第36週）で未勝利馬は全頭引退
- **現役上限**: 最大8歳末で引退（9歳以上は現役不可）
- **ピークアウト・不振引退**: 4歳以降、能力減衰や成績不振により毎年一定割合が引退
- **出走制限**: 1レースあたり **8頭限定**、レース出走後は **最低中2週** は出走不可（最短3週に1走＝年平均5〜7走）
- **開催週**: 月4週、年間48週（毎週2〜3場開催）

### 1.2 現役馬頭数・ピラミッドの推計
毎年600頭誕生した場合、各世代の残存頭数は以下のようになります：

| 世代 | 頭数推移と特徴 | 年間平均稼働頭数 |
| :--- | :--- | :--- |
| **2歳** | 6月〜12月（28週）に順次デビュー | 約 300 頭（年間換算） |
| **3歳** | 1〜9月（36週）は600頭、9月末に未勝利（約390頭）カット。10〜12月は約210頭残存 | 約 500 頭（年間換算） |
| **4歳** | 3歳勝ち上がり馬（約210頭）から約15%引退 | 約 178 頭 |
| **5歳** | ピーク期・一部引退（約25%引退） | 約 133 頭 |
| **6歳** | ピークアウト期（約35%引退） | 約 86 頭 |
| **7歳** | 衰退期（約50%引退） | 約 43 頭 |
| **8歳** | 最終現役年（8歳末で引退） | 約 15 頭 |
| **古馬合計** | **4歳〜8歳の現役馬合計** | **約 455 頭** |
| **総現役馬** | **全世代合計（年間平均）** | **約 1,255 頭** |

### 1.3 必要な年間・週間レース数の算定
- **年間延べ出走回数**:
  - 2歳（600頭 × 平均3.5走）＝ 2,100 走
  - 3歳（未勝利390頭 × 5.0走 ＋ 勝ち上がり210頭 × 7.0走）＝ 3,420 走
  - 古馬（455頭 × 平均6.5走）＝ 2,958 走
  - **年間総出走枠**: **約 8,478 走**
- **必要レース数**:
  - 1レース8頭限定であるため、年間必要レース数は **8,478 ÷ 8 ＝ 約 1,060 レース**
  - 年間48週で割ると、**1週あたり約 22〜23 レース** が理論的最適値となります。

> [!IMPORTANT]
> **開催競馬場数と1場あたりのレース数配分**:
> - **3場開催の週**: 各競馬場 **7〜8 レース / 日**（例: 東京 8R、京都 8R、小倉 7R ＝ 計23R）
> - **2場開催の週**: 各競馬場 **11〜12 レース / 日**（例: 東京 12R、京都 11R ＝ 計23R）
>
> これにより、現実のJRA・地方交流の開催規模（各場8〜12R）と完全に一致し、出走枠の余剰や不足なく8頭立てで満員になる美しい循環が成立します。

### 1.4 クラス別昇級ピラミッドと重賞・オープン成立性の検討
ユーザー条件による出走資格：
1. **２歳**: 新馬・未勝利勝利後に重賞・リステッド出走可能
2. **３歳春まで**: １勝クラス勝利後に重賞・リステッド出走可能（2勝以上）
3. **３歳夏〜秋**: 重賞2着以内、もしくは３勝クラス勝利馬が重賞・リステッド出走可能
4. **４歳以降**: ３勝以上、もしくは３勝クラス勝利馬のみが重賞・リステッド出走可能

- **検証結果**:
  - 3歳春のクラシック（皐月賞・桜花賞・ダービー・オークス・羽田盃・東京ダービー・NHKマイルC等）の出走資格馬（2勝以上馬）は、2歳秋〜3歳春の1勝クラスを勝ち上がった約70〜80頭が該当し、毎週の重賞・トライアル（2〜3レース＝16〜24枠）に中2週で十分供給できます。
  - 古馬の重賞・リステッド出走資格馬（3勝以上馬）は、4〜8歳全体で常時約 150〜170 頭が存在します。古馬の重賞・リステッドを年間約70〜80レース（週1.5〜2レース＝12〜16枠）配置することで、8頭立てが綺麗に成立します。
- **頭数不足への対応（結論）**:
  - 現行の **毎年600頭誕生でシミュレーションは過不足なく完結します**。
  - ただし、もし「1週あたり36レース（3場×各12レース）」等の過密番組を組むと、重賞や上級条件で8頭揃わず頭数割れが発生します。そのため、**週22〜24レース制** で設計するか、あるいは全場12R（週36R）に拡張したい場合は **年間誕生頭数を900〜1,000頭に増やす** 必要があります。今回は現行条件（600頭誕生・週22〜24R）をベースに完璧にバランスを取ります。

## 2. 競馬場（JRA 8場 ＋ 地方 4場）とコース形状・スタート枝線の設計

陸上競技場のような単調なオーバルではなく、実在コースの特徴（起伏、直線長、コーナー半径、スタート地点の引き込み線・ポケット枝線）をモデル化します。

  1600mポケット ──┐     │
                 ▼     ▼
┌──────────────────────────────────────┐
│ (4コーナー)                      (2コーナー) │

                   スタンド前直線 (525.9m / だらだら上り坂)

### 2.1 各競馬場の特性と主要スタート枝線
1. **東京（芝・ダート / 左回り）**:
   - 特徴: 雄大な大箱、直線 525.9m（上り坂あり）。
   - 枝線・ポケット: 芝2000m（1〜2コーナー奥ポケット・直線スタート）、芝1800m（向正面奥引き込み線）、芝/ダート1600m（向正面奥ポケット）。
2. **中山（芝内・外・ダート / 右回り）**:
   - 特徴: トリッキーな高低差、直線 310.0m（ゴール前急坂 2.2m）。
   - 枝線・ポケット: 芝1600m（1コーナー奥ポケット）、芝1200m（向正面奥引き込み線）、芝2500m（外回り向正面）。
3. **阪神（芝外・内・ダート / 右回り）**:
   - 特徴: 外回り直線 473.6m（ゆったり大箱）、内回り直線 356.5m、ゴール前急坂。
   - 枝線・ポケット: 芝1400m/1600m（向正面奥引き込み線）、ダート1400m（芝スタート枝線）。
4. **京都（芝外・内・ダート / 右回り）**:
   - 特徴: 淀の坂（登り降り）、直線は平坦（外回り 404m、内回り 328m）。
   - 枝線・ポケット: 芝1600m外回り（向正面奥ポケット）、芝1800m（2コーナー奥引き込み線）。
5. **中京（芝・ダート / 左回り）**:
   - 特徴: 左回り、直線 412.5m（急坂あり）。
   - 枝線・ポケット: 芝1200m/1600m（向正面奥引き込み線）。
6. **福島（芝・ダート / 右回り）**:
   - 特徴: 小回り・高低差あり、直線 292.0m（スパイラルカーブ）。
   - 枝線・ポケット: 芝1200m（向正面奥引き込み線）。
7. **新潟（芝外・内・ダート・直線 / 左回り）**:
   - 特徴: 日本最長直線 659.0m（芝外回り）、内回り 359m。
   - 枝線・ポケット: **芝1000m完全直線コース（第4コーナー奥からゴールまで直線のみの専用枝線）**。
8. **小倉（芝・ダート / 右回り）**:
   - 特徴: 平坦・小回り、高速スパイラルカーブ、直線 293.0m。
   - 枝線・ポケット: 芝1200m（2コーナー奥引き込み線）。
9. **大井（ダート外・内 / 右回り）**:
   - 特徴: 南関東の旗艦、ダート外回り直線 386.0m（日本最長ダート直線）。
   - 枝線・ポケット: ダート1200m（向正面奥引き込み線）、ダート2000m（スタンド前直線）。
10. **川崎（ダート / 左回り）**:
    - 特徴: コーナーがきつい小回り、直線 300.0m、川崎記念・全日本2歳優駿の舞台。
    - 枝線・ポケット: ダート1500m/1600m（コーナー奥引き込み線）。
11. **船橋（ダート外・内 / 左回り）**:
    - 特徴: スパイラルカーブ採用、直線 308.0m、かしわ記念・日本テレビ盃等の舞台。
    - 枝線・ポケット: ダート1000m/1600m引き込み線。
12. **盛岡（OROパーク / 芝・ダート / 左回り）**:
    - 特徴: **地方唯一の芝コース併設（芝外回り・ダート内回り）**、高低差 4.4m、直線 300.0m。マイルCS南部杯・不来方賞の舞台。
    - 枝線・ポケット: 芝1600m/ダート1600m引き込み線。

## 5. 検証手順

1. **番組表生成・整合性テスト**:
   - `python3 tests/test_race_program.py`（または検証用スクリプト）を作成し、全48週で週22〜24レース、年間約1,080レースが正しく生成されているか確認。
   - 12箇所の競馬場が適切にローテーションされているか確認。
   - 芝・ダート比率、距離分布（1000m、1200〜1600m、1800〜2000m、2400〜3000m以上）が偏りなく均等か検証。
2. **出走資格＆8頭立て・中2週制约の動作検証**:
   - 2歳、3歳春、3歳秋、古馬の出走資格チェックが要件通り動作するかユニットテスト。
   - レース出走後の馬が中2週以上あけて出走しているか検証。
3. **通年シミュレーション実行（1年間完走テスト）**:
   - 年間48週を一括実行し、全レースで8頭（または適正頭数）が出走し、頭数割れやエラーが発生しないことを確認。
   - 3歳9月末（第36週）で未勝利馬が正しく引退しているか、8歳末で引退しているかを確認。
